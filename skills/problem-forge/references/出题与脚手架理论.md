# 出题与脚手架理论：Agent 可直接执行的规则集

> 用途：给「题目拆解与变式设计师」预设做规则底座；也可直接当命题自检清单用。
> 适用范围：任意学科，示例以数学/物理为主；非数理学科把「模型」替换为「核心概念+方法」。
> 版本：v1（2026-11-04）。结构：质量检查表 → 难度画像 → 认知层级 → 脚手架 → 变式算子 → 问题提出 → 子题链规则 → 跨学科 → 来源。
>
> **检索环境说明（先读，影响来源可信度）**：本次会话 `web_search` 后端只返回模型记忆、不返回可核实 URL，插件会丢弃无来源结果（工作区 `web-search-bailian/README.md` 已写明该限制）；cn.bing / 360 / 百度 对本类查询返回被污染或按首词切词的无关结果。因此本文只把**本次真实抓取成功**的页面列为 A 级链接（arXiv API、aft.org、moe.gov.cn、neea.edu.cn、webbalign.org 等），经典文献只给**题录**（B 级），不编造链接。分级见 §9。凡标「教研经验」的条目是我的实践判断，不是实证结论。

## §0 三条使用约定

1. **先画像、再拆题**。不要先想子题，先把原题按 §2 打成 14 维向量，再决定补哪种脚手架。顺序反了，子题链会变成"又一堆题"。
2. **一次只动一个维度**。任何相邻两题（含变式）只能有一个因子/一个属性改变，否则学习者无法归因，你也无法诊断。依据：变异理论的「分离（separation）」原则，以及 AI 诊断 agent 的设计结论——"每个被改变的案例必须只改一个变量，否则答案变化无法追溯到单一想法"（[arXiv:2610.22949](https://arxiv.org/abs/2610.22949)）。
3. **规则优先于文采**。输出必须是可判定的：能打勾、能算出数、能指出反例。禁止"加深理解""培养素养"这类不可验证表述。

## §1 题目质量检查表（28 项，逐项可勾选）

判据：任一项打不上勾，**先改题，不要靠"讲课时解释"补救**。分组按"科学性 / 公平性 / 可解性 / 效度 / 区分度"。测量术语（难度系数 p、区分度 D、双向细目表）见 §2.3、§9-B；中国学段合规性依据见 [教育部义务教育课程标准（2022 年版）](http://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html) 与 [《中国高考评价体系》](https://www.neea.edu.cn/html1/page/16103/885-1.htm)。

### 1.1 科学性（题目本身是否成立）

- [ ] 1. 概念与符号无错：同一符号在全题只表示一个量；符号的默认含义符合本学段教材。
- [ ] 2. 量纲/单位自洽：等式两端单位一致，单位换算只出现一次且标注清楚。
- [ ] 3. 数据自洽：所有已知量代入后**存在解**，且解落在情境允许区间（时间 >0、角度 ∈(0,π)、概率 ∈[0,1]）。
- [ ] 4. 无矛盾条件（如同时给"匀速直线运动"与"加速度不为零"）。
- [ ] 5. 无隐性超纲：所需方法全部在该学段课标/考纲内；超纲方法若可用，必须另有不超纲通路。
- [ ] 6. 图形与文字一致：图上标注、坐标轴方向、比例关系不诱导错误结论。
- [ ] 7. 约定齐备：g 取 10 还是 9.8、π 取 3.14 还是保留 π、有效数字与近似要求，都在题干写明。
- [ ] 8. 结论口径明确：唯一解 / 有限组解 / 需讨论 / 无解，题干说明该答哪一种（"若无解请说明理由"）。

### 1.2 公平性（是否在测学科能力之外的东西）

- [ ] 9. 情境不依赖特定地区、学校、家庭条件（专有地名、需昂贵器材、需见过某装置）。
- [ ] 10. 背景知识不是解题必需：删掉情境中的百科信息后，学科路径仍完整。
- [ ] 11. 无敏感/不适内容（灾难、疾病、个体身体特征、可能引发焦虑的表述）。
- [ ] 12. 阅读负荷不越级：长句、生僻词、跨句条件关联不构成额外门槛；非语文学科不考语文。
- [ ] 13. 图形识读不是唯一通路：纯图题给出文字描述，纯文字题给出可作图的信息。（实证提示：多维度情境与图形依赖是产生群体偏差的常见要素，见 [arXiv:1704.07447](https://arxiv.org/abs/1704.07447)）

### 1.3 可解性（人能不能在规定时间内做出来）

- [ ] 14. 命题人自己完整解过一遍并计时，用时 ≤ 该题分值对应的考场时长。
- [ ] 15. 无"卡死点"：每个必要中间量都能从题干或前面小问获得，不需要外部常数表。
- [ ] 16. 一题多解可控：至少给出两类解法的评分点；若命题人不希望多解，需在题干限定方法或改问法。
- [ ] 17. 多小问有依赖逻辑：前一问是后一问的台阶或提示，不是两问拼盘。
- [ ] 18. 允许的辅助工具明确（计算器/公式表/尺规），并已按该条件核算难度。

### 1.4 效度（测的是不是想测的东西）

- [ ] 19. 目标是学科能力，不是计算耐力：与目标无关的重复运算已删或外包（给中间结果）。
- [ ] 20. 认知层级标注与真实解法一致：用 §3 的 SOLO/DOK 口径复核，标注层级 ≠ 实际层级就改标注或改题。
- [ ] 21. 每个错误选项对应真实错误概念：能说出"谁会选它、为什么会这样错"（选不出即删选项）。
- [ ] 22. 无暗示答案：选项长度/语法一致；排除法不能秒杀；图上不直接写出待求量。
- [ ] 23. 前置知识可列举：写出 3–6 个必需知识点，且能对到题库的知识点编码（双向细目表用）。
- [ ] 24. 复杂 ≠ 难：区分"结构复杂（DOK 高）"与"做不出来（p 低）"，两者混同会导致错标难度（[Webb DOK](https://www.webbalign.org/about/dok-explained) 明确区分 complexity 与 difficulty）。

### 1.5 区分度（能不能把人分开）

- [ ] 25. 预估难度 p：中档题 0.30–0.75；压轴题 p<0.30 时必须有小问保底（否则全空）。
- [ ] 26. 存在"部分正确"的中间状态：评分点可分，不是全对/全错二元。
- [ ] 27. 能写出 3 类不同水平的典型错法，且三类错法互不相同（相同说明题目只考一件事）。
- [ ] 28. 难度来源 ≥2 个因子（单一陷阱撑起全题 = 区分度虚高、信度差）；时间压力不是主要区分手段。

**命题失误速查（出现任一条即判废题）**：条件多余 / 条件矛盾 / 数据不自洽 / 超纲 / 暗示答案 / 一题多解失控 / 图形误导 / 一问多答口径不明 / 前问泄后问答案 / 情境信息量压过学科要求。

## §2 难度画像因子表

### 2.1 14 个因子（0=低，1=中，2=高）

| # | 因子 | 低 → 高 | 如何判定（可操作） | 对脚手架的影响 |
|---|---|---|---|---|
| 1 | 知识点数量 | 1–2 → ≥4 | 数解法链上不同知识点的个数（不含重复使用） | ≥3 时先做"知识点回炉题"，单个知识点各一题 |
| 2 | 认知步骤数 | 1 步 → ≥5 步 | 从条件到结论的最短推理链步数（每步一句话能说清） | ≥4 时给"步骤卡"或部分完成题，只留关键步 |
| 3 | 表征转换次数 | 单一表征 → ≥2 次 | 数"文字→图→式→表→图"的跨表征次数 | ≥1 次时单独插"翻译子题"（只做表征转换，不做求解） |
| 4 | 计算复杂度 | 口算 → 含参/多步代数/近似 | 是否需要 ≥3 行代数变形或保留字母参数 | 高时给"算过的中间量"，把计算与建模分离 |
| 5 | 情境陌生度 | 教材原型 → 真实陌生情境 | 情境是否出现在本学段教材/常见题型中 | 高时先做同结构熟悉情境题（"脱情境"再"回情境"） |
| 6 | 干扰/陷阱 | 无 → 多余条件+易混概念 | 数"解题用不到的条件数"与"易混概念对数" | 高时先给"标出无用条件"的判别子题 |
| 7 | 开放性 | 唯一路径 → 需自选策略 | 是否存在 ≥2 条都合理的主路径，且题干不指定 | 高时先给"方法选择"讨论题（只选方法不求解） |
| 8 | 隐含条件识别 | 显式给出 → 需自己挖 | 必要条件是写在题干，还是藏在图形/物理常识/边界条件里 | 高时给"圈条件"子题：只列条件与含义 |
| 9 | 抽象程度 | 具体数值 → 字母参数/一般性 | 结论是数值还是含参数的表达式/一般命题 | 高时先做"数值特例"，再推广（特殊化 → 一般化） |
| 10 | 结构耦合度 | 单对象单过程 → 多对象/多过程耦合 | 数需要联立/接力的过程数与对象数 | ≥2 时先拆成"单过程"独立子题，再拼接 |
| 11 | 结论形式 | 求值 → 证明/存在性/最值/讨论 | 看问法动词 | 证明/存在性类必须先给"结论模式"范例 |
| 12 | 图形依赖 | 纯文字可解 → 必须读图/作图 | 删掉图后是否信息缺失 | 高时先做"给文字画图"子题 |
| 13 | 时间压力 | 充裕 → 紧 | 预估用时 / 该题位可用时长 | 高时拆成限时小步；不要用时间压力当难度 |
| 14 | 语言负荷 | 短句 → 长情境多条件 | 单句字数、条件跨句数、从句嵌套数 | 高时先做"条件清单化"子题（把叙述压成表格） |

> 区分度提示：真正决定"是否做得出来"的多是 2/3/8/10（步骤、表征、隐条件、耦合）；而 1/4/5/14 更多影响"做得慢不慢"。画像时把这两类分开写。

### 2.2 画像输出模板（Agent 必须按此格式产出）

```
难度画像：[学科]｜[题型]｜预估 p ≈ 0.xx（±0.10）
高值因子（2 分）：2 认知步骤、3 表征转换、10 结构耦合
中值因子（1 分）：1 知识点数量、8 隐含条件
低值因子（0 分）：5 情境陌生度、6 干扰、13 时间压力
主难度来源一句话：因为"需要把文字条件转成 v-t 图，再在图上做两次面积分割"，共 2 次表征转换 + 2 个过程耦合。
可拆点（按优先级）：① 文字→图；② 单过程→双过程拼接；③ 图→式。
```

### 2.3 难度系数与预估（可直接算）

- **难度系数 p = 该题平均得分 / 该题满分**。p 越大越容易。经验分档：p<0.30 难，0.30–0.55 较难，0.55–0.75 中档，>0.75 容易（教研经验 + 常规教育测量口径；p 依赖样本，不同群体不可直接比）。
- **预估方法（无实测样本时用）**：p̂ = 1 − 归一化(0.30×认知步骤 + 0.25×表征转换 + 0.20×结构耦合 + 0.15×隐含条件 + 0.10×计算量)，再按学段基线平移。这只是排序工具，**不是统计估计**，必须在输出里注明"经验预估"。
- **区分度 D（极端分组）= 高分组得分率 − 低分组得分率**；D≥0.30 可接受，0.20–0.29 需修改，<0.20 淘汰（常规测量学口径，B 级题录见 §9）。
- **双向细目表（table of specifications）**：行 = 内容模块，列 = 认知层级（SOLO 或 DOK），格内填题号/分值与预估 p。作用是把"这张卷子考了什么"变成可核对矩阵。中国学段可用「必备知识 × 关键能力 × 学科素养 × 核心价值」四层做列维度（[《中国高考评价体系》](https://www.neea.edu.cn/html1/page/16103/885-1.htm)）。

| 内容模块 \ 认知层级 | 单点 | 多点 | 关联 | 抽象拓展 | 分值合计 |
|---|---|---|---|---|---|
| 模块 A | 题1 (p .85) | 题3 (p .62) | 题7 (p .38) | — | 24 |
| 模块 B | 题2 (p .80) | 题5 (p .55) | 题8 (p .30) | 题10 (p .18) | 32 |

> 设计规则：**同一层级的分值占比不得超过 45%**；相邻两个层级必须有题，不允许从"多点"直接跳到"抽象拓展"（教研经验）。

## §3 认知层级表：题目长什么样、上一层怎么加

判定口径统一为三问：①解题要用到**几个**相关信息单元？②单元之间是否**必须**建立关系？③是否需要**迁移**到新情境/新表征？

| SOLO（Biggs & Collis） | DOK（Webb） | Bloom 修订版 | 题目长什么样（可判定） | 上一层怎么加 |
|---|---|---|---|---|
| 前结构 prestructural | DOK 1 | 记忆/理解（碎片） | 题干信息与问法不匹配，学生答非所问；正确答案靠猜或抄 | 不用于命题；用于诊断"缺哪块知识" |
| 单点结构 unistructural | DOK 1 | 记忆/理解 | 只需**一个**信息单元 + 一次直接套用（"用 F=ma 代入求 a"） | 加第二处同源信息，要求分别套用（→多点） |
| 多点结构 multistructural | DOK 2 | 理解/应用 | 需要**多个**单元，但彼此独立、按顺序各做一次（多问并列、多步各自算） | 加一句"这两步之间有什么关系/能否合并"，强制建立关系（→关联） |
| 关联结构 relational | DOK 3 | 应用/分析 | 必须**整合**多单元成一个结构：用前问结论推后问、多过程守恒/联立、从整体看局部 | 换情境/换表征/要求一般化或给反例（→抽象拓展） |
| 抽象拓展 extended abstract | DOK 4 | 评价/创造 | 需要抽象出方法、迁移到陌生情境、或对结论本身做评价（"该方法何时失效""推广到 n 个"） | 换学科模型做类比迁移；或反过来要求"提出新问题"（§6） |

**层级判定示例（同一道力学题的四个层级）**

- 单点：给出 m、F，求 a。（一个单元，一次代入）
- 多点：分别求 a、2 s 末速度、2 s 内位移。（三个单元，各自独立）
- 关联：求 2 s 内位移，且已知摩擦因数，需先用整体受力求 a 再积分。（单元间必须串联）
- 抽象拓展：若 F 随时间线性增大，定性画出 a-t 图并说明"匀加速公式为何失效"。（迁移 + 评价）

> → **Agent 规则**：给题目定层级时，**不要看题目难度、只看结构**；标为"关联"的题必须在解析里出现至少一次"由上一问可得…"。标不上层级的题，按 §1 打回重写。

## §4 脚手架工具箱（何时给、怎么给、何时撤）

总原则来自 Rosenshine 的"小步呈现—示范—引导练习—检查理解—独立练习"序列（[Principles of Instruction, AFT 2012](https://www.aft.org/ae/spring2012/rosenshine)），以及认知负荷理论：新手期用强指导降低外在负荷，熟练后必须撤除，否则产生**冗余效应**（expertise reversal effect，B 级题录）。

| 类型 | 适用场景 | 具体做法 | 何时撤除 |
|---|---|---|---|
| 完整范例 worked example | 全新题型、新手；目标结构复杂 | 给"题面 + 完整解法 + 每步理由"，再给同构题 | 学生能独立完成同构题 2 次；熟练者直接跳过（避免反转效应） |
| 渐隐范例 fading | 从范例到独立解题的过渡 | 完整解 → 挖掉最后一步 → 挖掉中间步（填空式）→ 只给首步 → 独立 | 按"填空正确率 ≥80%"逐级撤；不要一次撤两级 |
| 部分完成题 completion problem | 步骤多但单步不难 | 给前 2 步，留关键步；或给结果让学生补过程 | 能补全 ≥2 题后转全独立 |
| 提示分级 hint ladder | 卡在某一步 | 级差设计：① 指向知识点 ② 指向方法名 ③ 给出首步式子 ④ 给完整第一步 | 用完 L3 后必须换同构题重做；提示层级不得越过"学生所需"（见下方实证警告） |
| 子目标分解 subgoal | 结构耦合高（多过程/多对象） | 把长链切成 2–4 个子目标，每个子目标一句问话 | 能自己划分子目标时撤（元认知成熟标志） |
| 类比 analogy | 新模型与已学模型同构 | **必须显式标注结构对应**（新情境的量 ↔ 熟悉模型的量） | 能自己说出对应关系后撤 |
| 可视化/多表征 | 表征转换是主难度源 | 文字↔图↔表↔式互译；先做"只翻译不求解"的子题 | 能在无图情况下自建图时撤 |
| 元认知提示 self-explanation | 会做但说不清；易混概念 | "为什么这一步可以这样做""如果改成…会怎样""这步用到了哪个条件" | 学生自发解释后撤 |
| 错误范例 error example | 高频典型错法 | 给一份有错的解答，让学生找错并说明原因 | 能独立预判错因后撤 |
| 检查清单 checklist | 收尾/检验阶段 | "量纲查了吗/边界值查了吗/取等条件成立吗/答案在范围内吗" | 内化为习惯后撤（可保留为卷面提示） |

**四条硬性约束（有实证支撑）**

1. **提示不得超出所需**：给超过学生需要的支架，成绩反而下降，且学生看不出额外支架与题目的关联（[arXiv:2006.16842](https://arxiv.org/abs/2006.16842)）。→ 规则：先用最低级提示；一次只加一级。
2. **类比不能只"给一个相似题"**：仅让学生先做类比题不足以保证迁移，还需直接帮助学生检验并修正其错误概念（[arXiv:1602.05697](https://arxiv.org/abs/1602.05697)）。→ 规则：类比题后必须有一问"这两个题哪里一样、哪里不一样"。
3. **撤除顺序固定**：提示 → 分解 → 范例（先撤"告诉你做什么"，最后撤"给你看怎么做"）。依据：fading 的通行做法（B 级题录 Renkl & Atkinson）。
4. **视觉支架优于纯言语**：言语+视觉组合条件下内在负荷更低（[arXiv:2602.08893](https://arxiv.org/abs/2602.08893)）。→ 规则：能画图就别只写话。

> **ZPD 可操作化**：一道题若"独立可解"则不是脚手架对象；若"给任何提示都不可解"则超出 ZPD。**脚手架只作用于"给 1–3 级提示后能解"的区间**。判定方法：命题人 / 教师试做时记录"卡在第几步、需要几级提示"。
>
> **争议提示**：范例效应对"熟练者"的边界并非铁律——有研究发现 worked example 对不同先备知识水平的学习者都有效（[arXiv:2405.16480](https://arxiv.org/abs/2405.16480)）。→ 规则：默认按 expertise reversal 撤范例，但若学生仍失败，允许回补范例，不要教条撤除。

## §5 变式算子表（一题多变的 14 个动作）

**先分两类（顾泠沅变式教学的核心区分，B 级题录）**：
- **概念性变式（conceptual variation）**：变的是"这个概念可以长什么样"——标准式/非标准式/反例，目的是让学生看到概念的本质属性不变、非本质属性在变。
- **过程性变式（procedural variation）**：变的是"通往结论的路径"——铺垫、阶梯、拆步，目的是把一条难路径变成可走的路径。

变异理论（variation theory）给出四种变化模式，可直接当算子使用：**对比 contrast**（与什么不同）、**分离 separation**（只变一个维度）、**融合 fusion**（多个维度同时变、但仍可分辨）、**概括 generalization**（在变化中看到不变）。前两者用于生成子题，后两者用于生成变式题（B 级题录 Marton & Booth）。

| # | 算子 | 怎么改 | 难度往哪走 | 风险/禁忌 |
|---|---|---|---|---|
| 1 | 换数 | 只换数值，结构不动 | ≈持平（除非改出非整数/病态数据） | 禁忌：换成无解、负数边长、非整数但要求精确值 |
| 2 | 加强条件 | 把"光滑"改"粗糙"、把"匀速"改"变速" | ↑（结构耦合/步骤） | 禁忌：加条件后使原方法失效却没给新工具（超纲） |
| 3 | 削弱条件 | 去掉一个已知量，改为可推 | ↑↑（隐含条件） | 禁忌：削弱后解不唯一，题干未说明"求范围" |
| 4 | 改结论形式 | 求值 → 求范围/证明/存在性/最值 | ↑（结论形式是独立难度源） | 禁忌：证明题未给结论模式范例，学生不知道"证到什么算完" |
| 5 | 逆命题 | 条件与结论互换 | ↑（需判断真假） | 禁忌：逆命题为假时直接当证明题；必须改成"判断并说明理由"或"举反例" |
| 6 | 特殊化 | 一般 → 具体值/边界情形 | ↓（常作入场题） | 禁忌：特殊化后掩盖了原题的一般性难点（要保留"再一般化"一问） |
| 7 | 推广 | 具体 → 字母参数/任意 n | ↑↑（抽象程度） | 禁忌：推广后超出学段工具（如需要数学归纳法而学段未学） |
| 8 | 换表征 | 式 ↔ 图 ↔ 表 ↔ 文字 | ↑（每次转换≈+1 难度档） | 禁忌：换表征同时换情境，两个变量一起动 |
| 9 | 换情境 | 教材情境 → 生活/科技/跨学科情境 | ↑（陌生度、语言负荷） | 禁忌：情境信息量压过学科任务；隐含新知识点 |
| 10 | 加约束 | 加"整数""至少""不超过""在区间内" | ↑（需讨论） | 禁忌：约束与数据矛盾，导致无解 |
| 11 | 去约束（开放） | 删掉唯一性条件，要求讨论 | ↑↑（开放性） | 禁忌：评分点不可判定；必须给"讨论到哪几类"的评分细则 |
| 12 | 多过程耦合 | 单过程 → 接力/联立 | ↑↑（结构耦合） | 禁忌：耦合处未给衔接条件（时间/位移/速度连续） |
| 13 | 加干扰条件 | 加多余但合理的条件 | ↑（陷阱识别） | 禁忌：干扰条件比有用条件更"显眼"，变成阅读测试 |
| 14 | 类比迁移 | 换学科模型（斜面 → 电路；数列 → 种群） | ↑（迁移） | 禁忌：只给类比题不给"对应关系"一问；对应关系不成立处未标注 |

**物理科专用变式（三类，教研经验）**
- **模型迁移**：同一方程换物理外壳（简谐振动 ↔ LC 振荡），要求写出"对应量对照表"。
- **条件变化**：改变初值/边界（如从"无摩擦"到"有阻尼"），观察结论的定性走向。
- **图像/实验**：把"给数据算结果"改成"给图像判读/给装置找误差来源"，这是物理特有的表征变式，常能同时提高 DOK 层级。

**数学科专用变式**：一题多变（改条件/改结论/逆向）、一题多解（同题多路径）、多题一解（不同题归一到同一模型）、一题多问（层层递进）。一题多解在**教学**上鼓励，在**测量**上会增加评分难度与评分者信度问题——用于考试时必须先写评分点（争议点，见 §10）。

**变式的单变量自检（Agent 必做）**：写出"原题 → 变式"的差异清单；若差异项 ≥2，删到只剩 1 项，或明确标注"本变式同时改变 A、B 两个维度"（仅在出"综合变式"时允许，且不得用于诊断）。

## §6 问题提出（problem posing）：What if not 的具体操作步骤

来源：Brown & Walter 的 "What if not?" 策略（B 级题录）——把题目拆成属性清单，逐个否定，看会长出什么新问题。

**五步操作（可直接执行）**

1. **列属性清单**：把原题拆成 5 类属性——①数据/数量 ②对象/元素 ③条件/约束 ④关系/运算 ⑤问法/结论。
2. **逐个否定**（一次否一个）：把某个属性写成"如果它不是这样，会怎样？"。例：原题"三角形是锐角三角形" → "若不是锐角三角形？"；"求最大值" → "若不求最大值，求什么？"。
3. **生成候选问题**：每个否定至少写 1 个可问句（不评判质量）。
4. **分类定级**：把候选分成四类——(a) 可解且答案唯一 (b) 需补充条件才可解 (c) 开放/多解 (d) 命题为假（→ 改成判断题或举反例题）。
5. **筛选入链**：按 §2 画像给每个候选打难度向量，只保留"比原题低 1 档或高 1 档"的 2–3 个进入子题链/变式组；跳档太大的降级后再用。

**另两法**
- **条件修改法**：固定结论、改条件（求"使结论成立的条件的范围"）；或固定条件、改结论。天然产生"求范围/讨论"类问题，适合做关联层到抽象拓展层的台阶。
- **逆命题法**：交换条件与结论；先判断真假，再决定出成证明题、反例题还是"补条件使之为真"题。

**"好问题"的 6 条标准（可判定）**
1. 问句只有一个明确的求解目标（不是"谈谈你的看法"）。
2. 答案可判定（数值/表达式/证明要点/评分点）。
3. 解题需要调用 ≥1 个本单元核心概念（不是纯计算）。
4. 难度落在学习者 ZPD 内（给 1–3 级提示可解）。
5. 能暴露一个典型错误概念（错法可预期）。
6. 与原题共享同一核心模型（保证回到原题时不突兀）。

## §7 子题链设计：12 条硬规则（附反例）

编号即执行顺序；违反任一条，链条重排。

1. **单变量递进**：相邻两题只变一个维度。
   反例：第 2 题既把斜面改成曲面、又引入摩擦——学生做不出时你无法判断是表征问题还是受力分析问题。
2. **同一核心模型**：全链共用同一个"骨架"（同一方程/同一守恒关系/同一几何构型）。
   反例：为凑难度在第 3 题换了另一类模型，链条变成题组，失去"回到原题"的功能。
3. **入场题必须 p ≥ 0.80**：第 1 题是"能独立做对"的题，让人先成功。
   反例：第 1 题就要求完整建模——学习者在起点失败，后续全部放弃。
4. **每 2–3 题一次"回头看"**：显式要求"用上一题的方法/结论"。
   反例：五道题各自独立，学生做完仍不知道它们是一类题（停在多点结构，升不到关联结构）。
5. **难度单调不减，允许一次回收**：整体上行；若中途回落，回落处必须配新脚手架。
   反例：第 3 题突然要求一般化证明（跳两档），第 4 题又回到代入计算——链条断裂。
6. **撤支架顺序固定**：提示 → 分解 → 范例；每次只撤一级。
   反例：第 4 题同时撤掉提示和范例，学生从"填空"直接跳到"空白纸"。
7. **末端必须能回原题**：原题的每个难点在链中出现过 ≥1 次；最后一题以**原题原貌**出现（或明确标注"现在回到原题"）。
   反例：链条结束时题目难度已超过原题，原题反而变成"简单题"，训练目标漂移。
8. **每问答案可判定**：给出答案形式与评分要点；禁止"体会一下""感受变化"。
   反例：子题 5 问"你有什么发现"——无法评分，也无法诊断。
9. **子题不得泄露原题答案**：若子题结论直接等于原题答案，原题失去测量价值。
   反例：子题 4 已经算出原题所求的量，原题变成抄写。改法：把原题改成"用子题结论解释/证明"。
10. **符号与术语全链统一**：同一物理量/同一几何对象在同一链中只能有一个符号与一种叫法。
    反例：第 2 题用 h 表示高、第 4 题用 h 表示深度——学生把时间花在解码符号上。
11. **层级覆盖 ≥2 层且不在同层堆量**：链条至少跨"多点 → 关联"两档；同层最多 2 题。
    反例：5 道题全是"多点结构"（各自套公式），练了 5 遍同一件事，能力没长。
12. **链长 3–7 题；超 7 题必须分段**（每段 3–4 题 + 一句阶段小结）。
    反例：12 题一条链，中间没有小结，学习者记不住走到哪、为什么走。

**回到原题的三段式（建议直接套用）**
`定位`（原题难在哪：引用画像里的高值因子）→ `组装`（把链中各步拼成完整解法，每步标注"对应子题 k"）→ `对账`（对照 §1 检查表复核：这题有没有被我改坏）。

## §8 跨学科迁移与通用解题步骤

### 8.1 数学 → 物理（三个"可教的动作"）

1. **建模**：先写"物理假设清单"（忽略什么、近似什么），再写方程。子题做法：单出"只写假设"的题（不求解）。
2. **量纲/单位检验**：任何结果先查量纲；量纲不符即判错，不需要重算。子题做法：给 4 个表达式选"量纲正确但系数错误"的那个。
3. **极限/特殊值检验**：令参数 →0/→∞/取等号，看结果是否符合物理直觉（如 m→∞ 时 a→0）。子题做法：给结论让学生"用两种极端情形检验"。

### 8.2 物理 → 数学（两个"可教的动作"）

1. **函数关系与图像**：把物理过程翻译成函数（v(t)、F(x)），再读图（斜率/面积/截距的物理含义）。这是物理题最常见的表征转换点。
2. **变化率与累积**：平均 → 瞬时、求和 → 积分的思想，先在"图像面积"层面建立直觉，再上公式。

### 8.3 通用解题五步（Polya 四步的工程化版本，B 级题录）

| 步 | 做什么 | 可判定检查（做完必须能回答） |
|---|---|---|
| 1 审题 | 圈条件、标未知、画图/列表 | 能一句话说出"已知什么、求什么、限制是什么" |
| 2 建模 | 选模型、写方程/关系 | 能说出"为什么用这个模型""它的适用条件我满足了吗" |
| 3 求解 | 执行代数/推理链 | 每步都有依据（公式名/定理名），不出现"显然" |
| 4 检验 | 量纲、极端值、数量级、边界、取等条件 | 至少通过 2 种检验；不通过就回到第 2 步 |
| 5 反思 | 一句话总结"这题的关键一步是什么""还能怎么变" | 能提出 1 个变式或 1 个反例 |

> → **Agent 规则**：子题链的每一步必须能对应上表的某一步；"检验"步必须单独成题至少一次（这是最常被跳过、也最拉分的一步）。

## §10 学术争议与使用边界（别把规则说成定论）

1. **germane load（相关负荷）是否独立存在**：Sweller 早期三分法被广泛使用；de Jong 等质疑把"相关负荷"当作独立可加负荷缺乏证据。→ 实践上仍用"降低外在负荷"做规则，但不要向用户断言"相关负荷可以精确测量"。
2. **expertise reversal 的边界**：多数研究支持"熟练者从范例中获益减少"；也有研究发现范例对各水平均有效（[arXiv:2405.16480](https://arxiv.org/abs/2405.16480)）。→ 规则写成"默认撤除，失败可回补"，不写成绝对律。
3. **"变式教学"≠"variation theory"**：顾泠沅的变式教学是中国本土的经验—实验体系（概念性/过程性变式），Marton 的 variation theory 是学习理论（四种变化模式）。二者常被等同，但并不等价；本文把前者当"算子清单"、后者当"为什么有效"的解释。
4. **DOK 不是难度尺**：DOK 量的是"内容/任务的认知复杂度"，难度还受先备知识、表征、时间影响（[WebbAlign](https://www.webbalign.org/about/dok-explained) 明确区分 complexity / difficulty）。→ 画像必须两栏分开写。
5. **p 值与区分度的样本依赖**：p、D 都要挂靠具体群体；不同学校/地区不可直接比较。经验预估必须标注"预估"。
6. **一题多解的教学价值 vs 测量代价**：教学上鼓励，考试上增加评分者信度风险。→ 考试用多解题必须预写评分点。
7. **"脚手架一定有益"是错的**：支架过量会损害表现（[arXiv:2006.16842](https://arxiv.org/abs/2006.16842)），隐性支架也可能让学生"做了但说不出"（[arXiv:1306.6544](https://arxiv.org/abs/1306.6544)）。→ 每次给支架都记录"为什么给、准备何时撤"。
8. **本文 §2.3 的预估公式、§7 的 p 阈值、§2.1 的权重**属教研经验，不是实证结论；作为**排序与自检工具**使用，不要当测量结果向外报告。
