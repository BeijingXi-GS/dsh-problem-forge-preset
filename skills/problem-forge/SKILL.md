# problem-forge 工作单

这是「题目拆解与变式设计师」的执行手册。系统提示词给了身份、铁律、五轴与工作流；这里给**每一步怎么做、做到什么程度算合格**。按 Gate 顺序走，每步产出直接进入下一步。

---

## 0. 开工六问（30 秒内想清楚）

1. **有没有答案、答案可信吗**：用户给了答案 → 模式 A（先盲解再核验，五类判定，再从正解反推解法族）；没给 → 模式 B（自解 + 双路线交叉验证）；解不出 → 模式 C（说卡点、请用户提供正解，不硬编）。适用类最终都要过 Lean（§2.6）。
2. **这道题值得拆吗**：它是「有结构的题」（有题眼、有可迁移的方法），还是「纯记忆题/纯熟练度题」？后者只适合做 O1 熟练度变式，不适合做 7 级台阶——直接说明并降级交付。
3. **拆给谁**：目标学生缺的是前置知识（→ 补诊断台阶）、缺表征能力（→ 加 O2）、缺论证（→ 加 O3/O8）、还是缺综合（→ 加 O6）？台阶方向由缺口决定，不是把所有步骤都铺一遍。
4. **主线怎么走**：目标 → 断点 → 台阶 → 验收 → 回收 → 迁移，六环一条线；先确定断点顺序，再排台阶，不按知识点目录排。
5. **形式化怎么落**：适用类（数学/几何/算法/计算）先想清楚「变量类型 + 假设 + 结论」三列，能不能写成 theorem；不能就在 Gate 1.5 处理，不许拖到交付。
6. **交付到哪**：`题目工坊/<题目简称>/`，三件套 + `formal/`；教师版只走一条主线，学生版只留题干/作答区（**零提示**，见 §9.5）。

## 0.5 编程/信息学题：额外加载 `code-training`（代码层）

如果本题是**编程 / 信息学题**（CSP-J/S、NOIP、洛谷、Codeforces、LeetCode、大学程设等），在 G4 台阶设计之后、G7 组装之前，**必须再加载 `code-training` 技能**（`skill` 工具，`name: code-training`），按它的「台阶 → 代码动作」映射给每个台阶补代码训练，并用三个工具收口：

| 动作 | 工具 | 硬要求 |
|---|---|---|
| 参考实现风格体检 | `code_style_audit`（contest 口径） | 取 3 条风格训练点；参考实现自身 <72 先改再出题 |
| 训练包结构校验 | `code_drill_check`（strict） | 0 error；每台阶 ≥1 代码动作，含 ≥1 产出型 |
| 真判题 | `code_judge` | 参考实现全过；骨架补全前必须失败；错解必须翻车；refactor 前后同数据都过 |

产物：`05_代码训练包.json` + 教师版 §7.6「代码落地区」+ 学生版「代码训练单」（零提示）+ 使用说明「代码排课」。**非编程题不加载、不塞代码层**；信息学题的 Lean 形式化（§2.6）与代码判题是两道关，都要过。

## 1. 时间盒与 Gate

| Gate | 做什么 | 参考耗时 | 产出 |
|---|---|---|---|
| G0 | 需求确认（≤3 问，含「有没有答案」） | 1–2 min | 参数表 + 答案模式 |
| G1 | 答案核验 / 独立自解 + 题目体检 | 5–12 min | 核验判定 + 体检表 |
| **G1.5** | **Lean 形式化验证（适用类硬门）** | **5–15 min** | **`formal/Problem.lean` + run 证据** |
| G2 | 反推解法族（模式 A/B） | 5–10 min | 解法族表 |
| G3 | 题眼、解法链、五轴画像 | 5–8 min | 画像卡 |
| G4 | 覆盖矩阵 + 接口表 + 难度曲线 | 5 min | 台阶地图 |
| G5 | 按难度定子题数（2–8）+ 逐题自解 + 子题 Lean | 15–30 min | 子题详解 + theorem |
| G6 | 变式（按空间 2–5 类，每类 ≥1）+ 逐题自解 + 变式 Lean | 10–20 min | 变式组 + theorem |
| G7 | 按主线组装 + 质量门 + 形态门 + 三硬门 + 交付 | 5–10 min | 文件 + 回复 |

单题总量控制在 45–75 分钟内（Mathlib 首次加载约 2–3 分钟）；超过说明台阶或变式数量超标，砍到 5 个台阶 / 4 道变式。

## 2. G1 答案核验 / 自解与题目体检工作单

先按 §2.5 判模式：有答案先盲解再核验（五类判定），没答案先自解（双路线），解不出走模式 C 求助。核验/自解完成后，再逐项打勾下表：

- [ ] 题面完整：图/表/单位/数据范围/符号定义齐全；没有「如图」却无图。
- [ ] 条件用全：每个条件在解法中至少用一次；用不到的条件要么多余，要么是你漏了隐藏用法。
- [ ] 无矛盾：条件之间不冲突（如「锐角三角形」与「最大角 100°」）。
- [ ] 独立解出：不看任何答案，完整写出解答；每一步可复算。
- [ ] 验算：把答案代回原题；数值题至少两种方式核对（代入/估算/特殊值）；**证明题**用「结论代特例 + 退化情形 + 符号恒等验证（通分/因式分解后比对）」三种方式核对。
- [ ] 边界与退化：端点、等号、分母为零、判别式为 0、图形退化情形。
- [ ] 多解检查：是否有第二解、增根、漏解；题目是否要求「所有」。
- [ ] 来源可核：用户给的出处能对上；对不上就写「出处待核」，不编造。
- [ ] 学段匹配：所需知识在目标学段内；超纲就标「拓展」或换解法。

**体检结论**三选一：`合格，可拆` / `有小瑕疵，修后拆（写明改动）` / `不合格，不拆（写明原因 + 替代方案）`。

> 常见坑：题面抄漏一个条件，导致原题无解或变简单；几何题没给图但文字描述有歧义；物理题单位混用。体检不通过就拆，后面全白做。

## 2.5 答案核验与解法族反推（有答案先核，没答案先解）

### 2.5.1 先判模式

| 模式 | 触发 | 第一动作 |
|---|---|---|
| A 有答案 | 用户给了最终答案/解析/证明/答案图片/链接 | **不看答案，先盲解** |
| B 无答案，能解 | 只给题 | 自解 + 第二条路线交叉验证 |
| C 解不出 | 自解失败/结果不稳 | 写卡点，请用户提供正解 |

**顺序不能反**：先读答案再「顺着解释」等于没核验——你会把答案的错当成前提，还觉得它很顺。

### 2.5.2 盲解 → 对照 → 五项核对

1. **盲解**：完整写自己的解，记下最终答案与关键中间量（不给用户看）。
   - **可审计做法**：单题也要先写自己的解再对照；批量或需留痕时，把盲解单独写进 `00a_盲解.md`（带时间），对照段只引用其结论。
   - 答案已经出现在上下文里时，不允许「顺着答案解释」——必须自己走一遍并写出可复算的中间量。
2. **对照**：逐项比较——最终答案（含形式：根式/区间/集合/单位）、中间关键量、讨论范围、取等/取极值条件。
3. **过程审查**（把用户答案当独立对象审，不预设它对）：
   - [ ] 结论代回/特例/极限/量纲是否成立；
   - [ ] 是否有伪证七类（P1 空降构造、P2 有限项代一般、P3 跳步、P4 充要方向错、P5 讨论不全、P6 条件没用全、P7 循环论证）；
   - [ ] 是否有「答案对但过程错」「过程对但答案抄错」「只给答案没过程」；
   - [ ] 定义域/分母/增根/多解/退化情形；
   - [ ] 严谨度是否低于题目要求（如用「显然」代替分类证明）。

### 2.5.3 五类判定与处理动作

| 判定 | 依据 | 处理 |
|---|---|---|
| ✅ 正确且严谨 | 结论与过程均可复算，无 P1–P7 | 直接进入反推与拆题 |
| ⚠️ 正确但不严谨 | 结论对，过程有跳步/伪证/表述问题 | 标出问题句，给**补严版**；拆题用补严版 |
| ⚠️ 部分正确 | 某问对/某步错/漏一种情形 | 断点定位表（第几步/哪类错），给修后全解 |
| ❌ 错误 | 结论错/反例成立/条件理解错 | 给**反例**（数值或构造）或正确结果；明确「不采用该答案」 |
| ❓ 无法判定 | 题面缺条件/答案形式无法核对/图片不清 | 列出缺什么、为什么无法判定；请用户补材料 |

**若判 ❌ 或 ⚠️**：先给「错在哪」的定位（错误类型 + 原句 + 正确写法），再给正确解；不要让用户自己去猜哪一步错。

**证据门槛（防操纵）**：判 ✅ 至少要有独立第二解法或机器验证；判 ⚠️ 必须指出「补哪一步就严格」；判 ❌ 必须给数值反例或严格构造；判 ❓ 必须列出缺什么条件。只凭「看起来像」不许下 ❌，只凭「结论一致」不许下 ✅。

### 2.5.4 从正确答案反推解法族（模式 A 必做；模式 B 解出后推荐）

只在答案**已确认正确**（或已修正）后做。六个动作：

1. **目标反推**：看结论形式猜方法族。
   | 结论长什么样 | 优先试 |
   |---|---|
   | 定值 / 恒等式 | 恒等变形、韦达、参数消去、对称性 |
   | 最值 / 范围 | 不等式、判别式、单调性、端点比较 |
   | 整数 / 整除 / 余数 | 数论、同余、构造、归纳 |
   | 轨迹 / 位置关系 | 坐标、向量、几何变换 |
   | 守恒量（物理/化学） | 能量、动量、电荷/原子守恒 |
   | 计数 / 概率 | 递推、容斥、对称、生成函数 |
2. **中间量反推**：从答案倒推「必须经过哪些中间量/引理」，写成链条：`答案 ← 中间量 ← 入口条件`。缺一环就说明还有隐藏步骤。
3. **特殊值/退化反推**：取端点、特例、极限、对称位置，看哪些量被条件「设计」掉了；这些就是命题人的抓手。
4. **多解法挖掘**：至少 **2 条真正独立**的解法（换工具，不是同一路线换写法），每条写：
   `入口 / 关键引理 / 适用条件 / 难度（D2 子维）/ 易错点 / 是否可推广`。
   **独立性判据**：两条解法在「入口条件 / 关键引理 / 失效情形」三项中至少两项不同；只换参数（如 $y=k(x-1)$ 与 $x=my+1$）算同一条，不能凑数。
   再标出**最简解法**（考场用）与**最通用解法**（教学用）。
5. **出题意图还原**：命题人想考哪个题眼、哪个条件是设计出来的、哪个数据是凑的；由此得到变式种子（哪些条件可换、换了考什么）。
6. **可迁移模板**：写「看到 X → 先试 Y → 因为 Z」的识别信号，以及步骤骨架（3–5 步），供学生套用与变式生成。

### 2.5.6 模式 C：解不出时怎么求助

不要硬编答案。用 `ask_user_question` 一次问清：

> 这道题我卡在「<具体步骤/引理>」，原因是「<缺条件/缺知识/结果不唯一>」。能否提供参考答案或解析？**只有最终答案也可以**，最好附关键步骤；如果是图片/链接也可以。

同时先交付能做的部分：题目体检、五轴画像、卡点分析、可能的路线（标「未验证」）。拿到正解后回到模式 A 重走核验。

## 2.6 Lean 4 形式化验证（强制；适用类无 `VERIFIED` 不交付）

工具来自已安装的 `lean-verify` 插件（`lean_env` / `lean_verify` / `lean_probe`）；完整协议、题型模式与速查见该插件的 `lean-formalization` 技能与本目录 `references/Lean形式化验证.md`。

### 2.6.1 适用与不适用

| 适用（必须逐题过 Lean） | 形式化目标 |
|---|---|
| 数学 | 求值、恒等式、不等式、方程/函数性质、数论、组合计数 → theorem + 证明 |
| 几何 | 坐标化/向量化：共线、垂直、共圆、切线、长度/角度关系；纯作图先转坐标 |
| 计算机算法 | 功能正确性、边界、循环不变式、小规模枚举；复杂度需显式代价模型 |
| 计算 | 数值、符号、级数、矩阵等可判定计算 → `theorem : f x = 值` |
| 物理/化学的计算内核 | 只验证代数/方程/守恒关系；物理语义另做人工检查并注明 |

**不适用（逐题写理由，不许默认跳过）**：纯尺规作图、实验设计、开放论述、无唯一答案的建模、无法离散化的连续语义 → 标「非形式化类」。

### 2.6.2 环境与工具（本机已就绪）

```powershell
lean_env action="status"
# ✅ Lean 4.35.0；工具链 ~/.dsh/lean-verify/toolchain\...
# Mathlib 工程：~/.dsh/lean-verify/mathlib-src（已构建，import Mathlib 可用）
```

- `lean_verify` 必须传 `projectDir="~/.dsh/lean-verify/mathlib-src"`（实数/代数/几何/算法都要 Mathlib）；`timeoutMs=600000`，首次 `import Mathlib` 约 1–3 分钟。
- **整组一次编译**：原题 + 子题 + 变式写在同一个 `Problem.lean`，只跑一次，省 Mathlib 加载时间。
- `lean_probe` 只用于 `#check` / `#eval` 探路，**不算证明**。
- 每次运行会生成 `~/.dsh/lean-verify/runs\<时间戳>-<label>\Verify.lean`，交付时贴这个路径作为机器证据。

### 2.6.3 状态（只有 `VERIFIED` 能交付）

| 状态 | 判定 | 能否写「已验证」 |
|---|---|---|
| `VERIFIED` | 退出码 0；无 `sorry`/`admit`；公理 ⊆ `[propext, Classical.choice, Quot.sound]` | ✅ 可以，附 run 路径与公理表 |
| `VERIFIED`（含 `native_decide`） | 同上，但用了编译器可信计算 | ✅ 可以，必须注明 |
| `UNVERIFIED-SORRY` | 有 `sorry`/`admit` | ❌ 不交付 |
| `FAILED` | 编译/类型错误 | ❌ 不交付，修陈述或证明 |
| `NOT_ATTEMPTED` | 仅限不适用类/未运行 | ❌ 不交付，写明理由 |

### 2.6.4 标准流程

1. 先完成自然语言解与第二解法（L0）。
2. 列「变量类型 / 假设表 / 结论」三列；每条假设标注对应题面哪句。
3. 写 `formal/Problem.lean`：`import Mathlib` + 逐条 theorem（`base_*`、`stepN_*`、`varA_*`、`varB_*`、`varC_*`）。
4. 一次 `lean_verify` 整组编译，记录退出码、run 目录、公理表。
5. 陈述对账：漏假设/多假设/语义漂移/空真逐条查；Lean 证的是 theorem，不证明它忠实于原题。
6. 写 `formal/VERIFICATION.md`（模板见 §10.4）。
7. 不通过就改坐标/改量词/拆引理/分情形，最多 3 轮；仍失败走模式 C，不硬编。

### 2.6.6 几何与算法怎么编码

- **几何**：优先坐标化。设点/线/圆为实数坐标，把「共线/垂直/相切/共圆/长度关系」写成代数等式或不等式；纯综合几何（辅助线、尺规作图）先转坐标，转不了才标「非形式化类」。
- **算法**：把程序写成 Lean 递归函数（`def f : ...`），再证规格 `theorem f_spec : ...`；循环用递归/`Finset` 归纳；边界（n=0/1、空列表）单独一条 theorem。
- **计算**：`theorem : f x = 值 := by decide` 或 `native_decide`（注明可信计算）；大数用 `#eval` 探路再用 `decide`/`norm_num` 证明。
- **复杂度**：Lean 不直接证「实际运行时间」；需显式 cost 函数与模型假设，只证「在该模型下 cost ≤ ...」，报告写清假设。

## 3. G3 题眼与认知步骤

### 3.1 题眼（只找一个）

题眼 = 决定解法成立的那一个观察或转化。判断标准：**没有它，题就卡住；有了它，剩下是常规操作。**

- 数学例：把 `a^x` 与 `log_a x` 的交点问题转化为 `f(x)=a^x - log_a x` 的零点，再用对称性——「对称性」是题眼。
- 物理例：把「恰好不脱离轨道」翻译成「支持力 N=0」——「临界条件翻译」是题眼。
- 信息学例：把「区间内不同数个数」转成「离线按右端点排序 + 树状数组」——「离线转化」是题眼。

题眼只计一次分（计入 C 或 A 或 T，选最主要的一项），避免 D2 各子维重复计分。

### 3.2 解法路线

给 1–3 条，标主路线。每条写到「关键步骤 + 为什么可行」为止，不写完整过程：

```
路线 1（主）：求导 → 驻点 → 最小值 → 恒成立转最值 → 解参数不等式
路线 2（备）：分离参数 → 求 g(x) 的值域 → 比较端点
路线选择依据：路线 1 计算量小但对参数讨论要求高；路线 2 更机械但需处理 x→0+。
```

### 3.3 认知步骤表（3–7 步）

| # | 认知动作 | 输入 | 输出 | 需要的知识 | 典型失败 |
|---|---|---|---|---|---|
| 1 | 识别 | 题面 | 判定为「恒成立」型 | 恒成立↔最值 | 误当方程解 |
| 2 | 表征 | 函数式 | 导数式 | 求导法则 | 链式法则漏项 |
| ... | | | | | |

认知动作只有六类：**识别、表征、转化、论证、综合、检验**。每个台阶新增一个动作，不要一步跨两类。

## 4. 五轴难度画像（锚点细则）

评分规则：D1/D3/D4/D5 取整数 0–5；D2 保留一位小数（四子维加权）；每维写 1–2 句依据，引用题面原句或解法事实；给置信度 high/medium/low。

### D1 重复度（越高越像已知题）

| 分 | 判定 |
|---|---|
| 0 | 教材、真题、经典题里找不到同构；主链路要自己设计 |
| 1 | 换了情境与数据形态，主链路不同，只借鉴思想 |
| 2 | 主链路眼熟，但关键转化或约束至少一处是新的 |
| 3 | 与某道经典题同构，靠背景/问法/数据区分 |
| 4 | 近似一比一，只改问法或数字 |
| 5 | 换皮题：背景一换，解法与坑完全相同 |

用途：D1 高不等于坏。若用于巩固，标「巩固题/模板题」；若声称「新题」，D1 ≥4 要改。**D1≥4 只在被当作「新题」或压轴时判问题**；用于巩固时按「模板题」处理，不扣体检分，也不计难度宣传。

### D2 思维深度（0–5，保留一位小数）

默认权重 R 0.30 / C 0.25 / A 0.25 / T 0.20，改了要写明。

- **R 推理链长度**：从读完题到可落地方案，需要多少个「单独想通的引理/步骤」。
  1 一步到位（套公式/直接算）；2 先转化再套；3 两三个引理，每步需验证；4 多步且中途要回溯；5 长链推理，需要整体性洞察。
- **C 因果与论证**：是否强迫你回答「为什么这样对」。
  0 纯计算；1 套定理即可；2 需说明适用条件；3 需分类讨论并证明不重不漏；4 直觉解会错，必须先证明/构造反例；5 需要非标准论证（反证、构造、不变量、极端原理）。
- **A 抽象与建模**：从文字/现实到数学模型的跨度。
  0 无需建模；2 识别标准模型（函数/方程/几何/概率）；3 需要选模型并翻译条件；4 需要自定义变量或重新定义对象；5 需要自创抽象（把操作变成状态、把图形变成代数结构）。
- **T 迁移与跨方法**：是否要把两个领域的方法互相改造。
  0 单一模板；2 同一领域内换工具；3 跨章节组合；4 跨学科迁移（数学↔物理）；5 两个领域的方法必须互相改造后才能拼上。

**反模式**：R 高但 C/A/T 都低 = 「长但不深」的机械长链，评语要点破；C 高但 R 低 = 「一个洞察定生死」，适合做压轴小题。

**题眼归属（固定字段）**：题眼只计一次分，写成 `题眼归属：C / A / T（本题＝…）`，并说明为什么归这一项；台阶复用同一归属，不重复计分。

### D3 知识叠加（0–5）

先列知识点标签（如：二次函数、导数、单调性、极值、恒成立、分离参数、分类讨论、数形结合……），再判结构：

- **单点**：只需 1 个考点。
- **串联**：A 的结论是 B 的输入，缺一环就断（最典型的「叠加」）。
- **并联**：多个考点可任选其一（会一个就能做）。
- **嵌套**：在一个方法/结构里再套一层（如「分类讨论里再解一个恒成立」）。

耦合强度：强耦合（改一个另一个必须跟着改）vs 拼装（各段独立）。

| 分 | 判定 |
|---|---|
| 0 | 单一模板，一步调用 |
| 1 | 单一知识点但要求熟练/变形 |
| 2 | 一主一辅，辅知识点只做工具 |
| 3 | 两个知识点强耦合，或三个串联 |
| 4 | 三个以上知识点构成依赖链 |
| 5 | 三层嵌套，或需要自定义中间结构来承载 |

**反模式**：D3 高而 D2 低 = 「大杂烩」，知识点多但每步都浅，不要当难题推荐。

### D4 计算与表征负荷（0–5）

两来源相加：**计算负荷**（借鉴 drifter_飘零 的五维拆分）+ **表征负荷**。

计算负荷五维（顺序不可跳，补差时按这个顺序补）：

1. **基础数值计算速度/数感**：能否秒算 12×10；能否快速判断结果大致对不对。
2. **固定运算规则的理解**：多项式乘法的项数/形状；只知道展开、不知道结果该长什么样 → 算完也检查不了。
3. **固定案例的积累**：背下常见结果（十字相乘、完全平方系数）——能提速，但换板块会掉，且背错会「以为算对、考场上检查不出来」。
4. **固定技巧的掌握**：分离常数、换元、整体代换；同时要会用更快的通法（如求导），别只会技巧。
5. **代数结构敏感度**：该换什么元、是否齐次、出现「消不掉的怪项」时能否回查来源。

表征负荷 = 表征转换次数（文字↔图↔表↔符号）+ 阅读量与干扰信息。

| 分 | 判定 |
|---|---|
| 0 | 口算一两步，单一表征 |
| 1 | 2–3 步常规运算，无符号讨论 |
| 2 | 多步常规运算，或一次表征转换（文字→式子/图→式） |
| 3 | 较长运算链，或含参数讨论，或两次表征转换 |
| 4 | 需要选计算策略（换元、设而不求、整体代换、估算），或表征转换 ≥3 次 |
| 5 | 计算本身就是难点：繁杂代数、多变量、需构造辅助量、数据「丑」到必须估算/放缩 |

**D4 高 / D2 低 = 假难**。典型信号：每步都会，但算到一半就错；换一组好算的数据题就变简单；答案数字很丑但方法平庸。

**计算错因规则**：学生算出「怪数/消不掉的项」时，正确动作是**回查来源**（符号、项数、条件用错），不是硬改答案。台阶里要专门设一个「回查」动作，并教学生「结果该长什么样」的自检标准。

### D5 陷阱与决策负荷（0–5）

| 分 | 判定 |
|---|---|
| 0 | 直路，无干扰 |
| 1 | 一个常见易错点（漏定义域、单位、符号、端点） |
| 2 | 需要先判断适用条件，或有分类讨论的入口 |
| 3 | 默认直觉解法必错，需先验证或构造反例 |
| 4 | 多个坑串联，或中途要做方法选择并承担风险 |
| 5 | 题面含误导信息/伪条件，必须识破伪证结构（循环论证、特值代替证明、把必要条件当充分） |

**要求**：每个坑必须对应一个明确误区，能写出「学生为什么会这么想」。靠文字游戏制造的坑不算难度，算坏题。

**坑型标签（写画像时必选）**：`方向错`（充分必要反了）/ `不完备`（漏一类情形）/ `隐含条件`（条件藏在图或常识里）/ `诱导信息`（图或表述把人带偏）。「不完备型」用「完备性清单」台阶处理，不要错配成 O8 错解辨析。

### 4.1 一句话判断

| 情形 | 判断 | 处方 |
|---|---|---|
| D2 高、D3 高 | 真难（思维+综合） | 台阶沿 D2/D3 逐级拆 |
| D2 高、D3 低 | 真难但窄（单点深挖） | 台阶重点补表征与变式，别硬加知识点 |
| D2 低、D3 高 | 大杂烩 | 拆成并联小问，或改用综合训练定位 |
| D2 低、D4 高 | 假难（计算繁） | 先降 D4 出同构题，再逐步加计算 |
| D2 低、D5 高 | 坑题 | 拆出每个坑单独设问，教「识别信号」 |
| 各轴都低 | 没难度 | 只做熟练度变式（O1），不做台阶 |

### 4.2 坏题旗标（命中就写进体检，不许沉默）

来自 drifter_飘零 的卷面/单题质检视角，六类旗标：

| 旗标 | 识别信号 | 处理 |
|---|---|---|
| **纸老虎** | 条件写得吓人，翻译完内核很简单（「被吓到」） | 标「纸老虎」，可做台阶/入场题，不当压轴 |
| **全或无** | 看出来就会、看不出来就零；中间层拿不到任何分 | 拆台阶或改设问（加中间问），否则判「伪区分度」 |
| **秒杀通道** | 代特值、取前几项、猜结论、端点代入能绕过结构 | 做「截断攻击」：能绕过就堵通道或降级使用 |
| **换壳** | 外壳是后段板块（解析几何/数列），内核是低学段题 | 标「换壳题」：难度虚高，适合降维台阶，不适合标「难」 |
| **位置错配** | 用于题单/卷子时，顶级难度放在中档位置（或反之） | 调位置；否则中段归零、尾部仍高分，分布双峰 |
| **伪证** | 答案/解析里关键构造凭空出现、只验证有限项、跳步、方向错、讨论不全 | 见 §8「答案与伪证七类」，重写答案或降级为「待核」 |

## 5. G4 台阶设计工作单

### 5.1 台阶类型与顺序

| 类型 | 作用 | 典型问法 | 是否计入正式台阶 |
|---|---|---|---|
| T0 诊断 | 测前置知识，决定从哪层开始 | 「先做这 3 个小问」 | 否（答错降层） |
| T1 复现 | 最小实例，直接调用定义/公式 | 「当 a=1 时，求 f(1)」 | 是 |
| T2 表征 | 同一结构换表征 | 「把图中的关系写成式子」 | 是 |
| T3 题眼 | 隔离关键转化，给 H1 提示 | 「要证 A，先证 B」 | 是 |
| T4 组合 | 把前两级串起来，接近原题 | 「用上面的结论求……」 | 是 |
| T5 原题 | 完整原题 | 原题照抄（可加小问引导） | 是（终点） |
| T6 迁移 | 原题后检验迁移（可选） | 换情境/逆向 | 否（变式组） |

默认骨架：`T0? → T1 → T2 → T3 → T4 → T5`（T0 诊断可选且不计入数量；T5 原题为终点，**不计入子题数**）。**这是模板不是配额**：按 §5.2 的难度表取 k，不需要每类都出现；省掉某类的前提是它不唯一负责某个认知步骤/断点——否则就是漏步骤，返工。

### 5.2 数量（按难度定，不许漏）

**先数两步，再定子题数**：

1. 数原题**认知步骤** $n$（Gate 3 拆出的 3–7 步）与**断点** $b$（1–4）。
2. 按难度取子题数 $k$：

| 档 | 判据（满足任一） | 子题数 $k$ | 说明 |
|---|---|---|---|
| 基础/单点 | $n\le3$ 且 D2≤2.5 且 D3≤2 | **2–3** | 不硬凑 4 道；深度不够用变式补，不算台阶 |
| 中等 | $n=4–5$，或 D2 3–4，或 D3 3–4 | **4–5** | 默认档 |
| 难/综合 | $n\ge6$，或 D2≥4.5，或 D3≥5 | **5–7** | $k$ 可等于 $n$；允许 $n+1$ |
| 竞赛/压轴 | $n\ge6$ 且 D2/D3 高 | **6–8** | 可加诊断/缓冲台阶，仍不许漏步骤 |

3. **硬约束**：$k \ge b$；每个认知步骤至少 1 道子题覆盖；每个断点至少 1 道台阶接住；**覆盖矩阵不许有空行**。宁可多一道，不许漏一个断点/步骤；漏了返工。
4. 缓冲台阶 0–2 道（只做熟练度/防跳崖，不新增断点，写理由）。
5. 报告口径：写「$n=…$，$b=…$，取 $k=…$，理由：…」；不许只报「默认 5 道」。
6. 每个台阶给 D2 与 D3 档位（台阶层 D2 允许 0.5 粗粒度 + 一句话依据；精确加权值只对原题给），画一条曲线：整体单调上升；允许一次回落（巩固），回落要写「为什么在这里停一下」。
7. 最后一台阶到原题的跨度：只允许「一步之遥」，且这一步必须是前面练过的动作。

示例曲线（D2 总分，中等题 $k=5$）：

```
T1 1.2 ─ T2 2.0 ─ T3 2.6 ─ T4 3.0 ─ T5(原题) 3.6
```

示例口径：$n=5$、$b=2$、D2=3.4、D3=3.0 → 中等档，取 $k=4$（2 个断点各 1 道 + 1 道关键步骤 + 1 道缓冲），覆盖矩阵 5 行全满。

### 5.3 接口表（必须显式）

三种接口，选一种并写清符号：

1. **结论复用**：「第 2 题证得 △ABC≌△DEF」→「第 3 题直接用对应边相等」。
2. **中间量复用**：「第 1 题算出 f'(x)=ln x+1−a」→「第 2 题令 f'(x)=0 求驻点」。
3. **方法复用**：「第 2 题用分离参数法」→「第 3 题对另一个参数同样分离」。

检查：把接口表倒着读一遍——**删掉第 k 题，第 k+1 题会怎样？** 分三档，不要只用二值判断：

| 档 | 现象 | 判定 |
|---|---|---|
| **强** | 做不了 | 串联（合格） |
| **中** | 能做，但要多绕一步 / 多踩一个坑 / 退化为试错 | 算串联；必须写明「多绕的那一步是什么」 |
| **弱** | 可原样完成 | 并排练习（删题或合并） |

**方法复用型接口**（第 k 题只提供了「从哪入手」的入口）按「中」档处理，标「可替代」：删掉后能做，但会退化为直觉/试错，仍算串联。

### 5.4 覆盖矩阵

| 原题认知步骤 | 子题 1 | 子题 2 | 子题 3 | 子题 4 | 原题 |
|---|---|---|---|---|---|
| 步骤 1 识别 | ✓ | | | | ✓ |
| 步骤 2 表征 | | ✓ | | | ✓ |
| 步骤 3 题眼转化 | | | ✓ | | ✓ |
| 步骤 4 论证 | | | | ✓ | ✓ |

规则：矩阵每一行至少一个 ✓；每一列至少一个 ✓；没有对应原题步骤的子题删掉。

### 5.5 提示分级（只进教师版，学生版零提示）

| 级别 | 给什么 | 放在哪 | 例（几何证明） |
|---|---|---|---|
| H1 方向 | 看哪个条件/画什么图/回忆哪个定理 | 教师版提示卡 | 「注意中点，想想中位线」 |
| H2 关键观察 | 题眼的一半 | 教师版提示卡 | 「取 BC 中点 M，连 AM」 |
| H3 半成品 | 给出开头/关键式子 | 仅教师版 | 「延长 AM 至 D 使 MD=AM，连 BD」 |

**学生版一个提示都不印**：不出现「提示」「卡住看提示」「<details>」；学生卷面只写题号/题干/作答区。教师按卡住信号决定给 H1/H2/H3，给完让学生自己写，不替学生写。

禁止：H1 里出现具体辅助线；H2 里出现完整证明思路；任何提示直接给出答案。

### 5.6 认知负荷控制

- 每台阶新增概念 ≤1 个；新增符号 ≤2 个；文字量 ≤原题的 80%。
- 新手（低年级/基础弱）：T1/T2 用 worked example（完整范例 → 同构练习）；熟练者（拔高）删掉范例，直接给问题（ expertise reversal，见参考）。
- 台阶之间不要引入新的情境背景；换情境放到变式组，避免同时加「新情境 + 新方法」。

### 5.7 六条硬约束（来自飘零 + 教研理论，违反就重排）

1. **入场题必须能独立做对**（经验 p ≥ 0.80）：第 1 题就让人成功，否则后面全部放弃。第 1 题不能要求完整建模。操作口径：**3 分钟内、无提示、约 80% 目标学生能写出答案**——这是经验预估，不是统计估计。
   - 若母题本身是「全或无」型（见 §4.2），**先拆台阶再谈 p**：拆完重新判一次旗标是否已撤销；撤销不了就只把母题放在中档位。
2. **每 2–3 题一次「回头看」**：显式要求「用上一题的方法/结论」，否则学生停在多点结构，升不到关联结构。
3. **按入口分叉设计，但只走一条主线**：同一题至少准备三条通路——①模板/常规法 ②从结论反推 ③保底策略（猜结论 + 验证/特值试探）。**分叉只作教师应急（学生卡住时换哪条），不并排讲；学生版只走主线。** 飘零的原话：题型积累不总是正面的，先验模板会把新题强行归入旧类，反而堵死入口。
4. **符号与术语全链统一**：同一对象一个符号、一种叫法；第 2 题用 h 表示高、第 4 题用 h 表示深度，是低级但致命的台阶断裂。
5. **层级覆盖 ≥2 层且不在同层堆量**：至少跨「多点 → 关联」；同一层级最多 2 题，5 道题全是套公式等于练了 5 遍同一件事。
6. **子题不得提前算出原题答案**：若某道子题的结论直接等于原题所求，原题就失去意义。改法：① 把原题改成「用上面的结论证明/解释……」；② 删掉该子题，把结论改成「观察/猜想」；③ 对定值/恒等式型证明题，把组合台阶的结论写成**等价但不同形**（如证 $|AF||BF|=|AB|$），把最后一跳的等价变形留给原题。③ 会让无泄漏项成为边界情形：质量门第 5 项按「结构性泄漏上限」评，扣分并注明，不要假装满分。

## 6. G5 子题撰写模板

每道子题按这个格式写全，缺项就是没写完：

```
### 台阶 k｜子题 k（类型：T1/T2/T3/T4）
- 目标：学完这题，学生能做到……
- 新增：知识点 / 思维动作（只写一个）
- 接口：输入 ← 上一题……；输出 → 下一题将用到……
- 题干：（完整、无歧义、符号已定义）
- 答案：……
- 解析要点：3–5 步，每步一句为什么
- 评分点：2–3 个可给分的动作
- 提示：H1…… / H2…… / H3……（只写进教师版，学生版不出现）
- Lean：theorem 名 / 状态 / 陈述对账（见 §2.6）
- 常见错误：错误表现 → 背后误区 → 对应回退到哪一题
- 通过标准：独立完成 + 能口头解释关键一步
- 预计用时：x 分钟
- 对应原题步骤：步骤 x
- 难度：D2=…，D3=…
```

**紧凑版**（单题交付、子题 ≤6 道时可用）：把「评分点 / 提示 / 常见错误」合并为 1 行（分号分隔），其余字段仍写全；不要为了省行把解析压成一句空话。

好/坏示例（同一道导数恒成立题）：

```
坏：第1题 求 f(x)=x²−2x 的最小值；第2题 求 f(x)=x²−2x+1 的最小值；
    第3题 讨论 f(x)=x ln x−ax 的单调性。
    → 三题并排，第1题的结论第2题没用，第3题也没用；只是把原题拆小。

好：第1题 求 g(x)=ln x−x 的最大值（结论：g(x)≤−1）；
    第2题 用第1题结论证明 ln x≤x−1（接口：第1题的最大值当上界）；
    第3题 令 t=ln x，把「e^t≥t+1」翻译成第2题的形式（接口：方法复用）；
    第4题（原题）……
    → 每题的输出都是下一题的输入，最后自然落到原题。
```

## 7. G6 变式设计工作单（类别动态，至少两类）

### 7.1 变式类目（A–F，可扩展）

| 类 | 名称 | 定义 | 判据 | 常用算子 | Lean 要求 |
|---|---|---|---|---|---|
| **A** | **同质异述** | 本质相同，描述/表征/情境不同 | 第一步 + 知识条目 + 洞察相同；D2 不变 | O2、O7 | 同一命题的等价实例：证 `P ↔ Q` 或复用同一 theorem |
| **B** | **同质增条件** | 本质相同，但加条件/参数/耦合，D2 或 D3 升 ≥1 | 多一个条件/参数/模型 | O4、O5、O6 | 增假设的强命题，或扩展结论 |
| **C** | **形似神异** | 表面相似，默认解法失效，需换解法/更难知识 | 老办法失败（给反例）；需新引理/工具 | O3、O8、O5 特殊化 | 先证「默认命题为假」，再证正确命题 |
| **D** | **逆向/换设问** | 结论↔条件、求值↔范围↔存在↔恒成立 | 需反向推理；正推走不通或需补逆命题条件 | O3 | 证逆命题/范围/存在性，或给反例 |
| **E** | **错解辨析** | 给错误解法找错、判断伪证 | 错误是学生真会犯的 | O8 | 证反例或指出漏洞；正确解仍须 VERIFIED |
| **F** | **推广/特殊化** | 一般化、参数化、2D→3D，或取特殊情形 | 结论范围变化，需补边界讨论 | O5 | 更强/更广命题，边界单独一条 theorem |

**类目可扩展**：A–F 不够用时自定义 G/H…，写清定义、判据、轴变化、Lean 要求；不许写「其他」糊弄。

### 7.2 九类算子与类别映射

| 算子 | 操作 | 主要影响 | 对应类 | 典型做法 | 风险 |
|---|---|---|---|---|---|
| O1 换数据 | 只改数字/字母 | 不变 | 熟练度 | 2→3、a>0→a<0 | 答案不整 |
| O2 换表征 | 文字↔图↔表↔符号 | D4↑、A↑ | A | 解析式→图像；文字→示意图 | 图画错、信息丢失 |
| O3 换设问/逆向 | 求值↔范围↔存在↔恒成立 | R↑、C↑ | C/D | 「求 a」→「求 a 的范围」 | 逆命题不成立 |
| O4 改条件 | 加强/减弱/替换/删条件 | C↑、D3± | B | 「锐角」→「任意」 | 多解/无解 |
| O5 推广/特殊化 | 具体→一般、2D→3D、参数化 | A↑、T↑、D3↑ | B/F（推广）、C（设坑特殊化） | n=3→n；三角形→四面体 | 超纲、结论不成立 |
| O6 加耦合 | 把原题嵌入另一模型 | D3↑↑、R↑ | B | 原题作中间步骤 | 变成两道题拼接 |
| O7 换情境 | 生活/物理/经济情境 | A↑、D4↑ | A | 函数→利润/运动 | 情境增加无关阅读 |
| O8 错解辨析 | 给错误解法找错/判伪证 | C↑、D5↑↑ | E | 给 2–3 个解法判对错 | 错法不真实 |
| O9 拆步 | 只考其中一步 | D2↓ | 台阶/补差 | 只求导、只解不等式 | 太碎 |

### 7.3 类数与道数（按难度/变式空间定）

| 题档 | 最少类数 m | 建议道数 | 构成要求 |
|---|---|---|---|
| 基础/单点（$n\le3$，D2≤2.5，D3≤2） | **2** | 3–4 | 1 个同质类（A/B）+ 1 个异质类（C/D/E/F） |
| 中等 | **3** | 4–5 | 至少 A/B 之一 + 至少 C/D/E/F 之一 |
| 难/综合 | **3**（可 4–5） | 5–6 | 同上，建议含 C 或 D |
| 开放/多维度 | 3–5 | 5–6 | 可自定义扩展类 |

规则：
- 每类至少 1 道；**至少 1 个同质类 + 1 个异质类**——2 类题也要满足。
- **2 类必须写「类别裁剪说明」**（为什么第 3 类没有空间）；3 类以上写「类目选择理由」。
- 选 C 就必须附反例（Lean `¬` 或严格数值反例）；不选 C 不强制。
- 变式空间确实枯竭时，可以只出 2 类，但必须写明「哪一类没有空间、为什么」，不许硬凑假类。
- O1/O9 只算熟练度/台阶，不能顶替任何一类。

### 7.4 每道变式的必填字段

```
变式 v｜类别：A/B/C/D/E/F（或自定义 G/H）｜算子：O?
- 类别判据：A 第一步+知识+洞察相同；B 新增条件/参数且 D2 或 D3 升 ≥1；C 默认解法失败（反例）；D 需反向推理；E 找错/判伪证；F 推广/特殊化且补边界
- 改动：……
- 轴变化：D2 / D3（A 类必须写「不变」）
- 同/上/下层：……
- 题干：……
- 答案与解析要点：……
- 与主线关系：延伸第 k 环
- 反例（C 必填）：……
- 逆命题检查（D 必填）：……
- Lean：theorem 名 / 状态 / run 目录
- 风险：……
- 验收：……
```

### 7.5 变式有效性三判据（出完必须自检）

1. **同题重做**：连表征/情境都没换，只改数字 → 判 O1 熟练度，不计入变式集合。
2. **换皮**：只换外壳、没动条件/设问/结构 → 可作为 A 类，但必须标「D1 升高，思维不变」，不许冒充 B。
3. **难度塌陷**：新增退化解法（代特值、取前两项、猜结论、端点代入）→ 做「截断攻击」，能绕过就堵通道或降级。

### 7.6 变式也要 Lean 验证

- 同一 `formal/Problem.lean` 里加 `varA_*` / `varB_*` / `varC_*` / `varD_*` …，一次编译。
- A 类：证等价 `P ↔ Q` 或直接复用原 theorem（换变量名不算新证明，注明即可）。
- B 类：写成带新增假设的强命题；结论范围扩大时给边界定理。
- C 类：**先证反例**（`¬` 命题或 `#eval` 反例），再证正确命题；没有反例的 C 不交付。
- D/E/F 类：逆命题、错解反例、推广命题各自一条 theorem；不能复用原 theorem 冒充。

## 8. 学科校验清单

### 8.0 通用：答案质量与伪证七类（证明题必查）

答案本身是审查对象，不是「能对上结果就行」。逐条查：

| # | 伪证模式 | 识别问句 | 处理 |
|---|---|---|---|
| P1 | **空降关键对象** | 辅助函数/通项/不等式是突然出现的吗？「怎么想到的」有交代吗？ | 补来源，或改用可推导的构造 |
| P2 | **有限项代替一般** | 是否只验证了前几项/特例，就宣称「对任意成立」？ | 补归纳/一般性论证 |
| P3 | **跳步** | 从 A 到 B 的可达性论证了吗？「平移/变形后仍成立」证了吗？ | 补中间步 |
| P4 | **方向错** | 充分/必要条件是否说反？「A 的充分条件是 B」是否被当成「A 推出 B」？ | 改方向并重写 |
| P5 | **讨论不全** | 参数正负、端点、判别式为 0、图形退化，都覆盖了吗？ | 补分类或注明「不讨论」 |
| P6 | **条件没用全/用了题外结论** | 每个条件都用了吗？有没有引用题设之外的定理？ | 补用或删条件 |
| P7 | **循环论证** | 结论是否在证明中途被当作已知用了？ | 重写 |

附加：答案的严谨度**不得低于要求学生达到的严谨度**（否则会造成阅卷标准不确定，不能当评分样例）。

模型误判（如把「内侧轨道」当杆模型）不属 P1–P7 的证明错误，但按 P6「条件没用全」记录，并在物理「模型/约束类型」检查项判死。

形式化验证（强制，适用类）见 §2.6 与 `references/Lean形式化验证.md`。

### 数学
- [ ] 每个数值代回原式验算（至少一遍手算，不靠直觉）。
- [ ] 几何：图形可构造（给定条件能画出，或用坐标验证关键关系）；辅助线不唯一时答案一致。
- [ ] 定义域/值域/分母/根号/对数真数逐项检查。
- [ ] 增根（平方、去分母）、漏解（分类讨论是否穷尽）、多解是否符合题意。
- [ ] 不等号方向、取等条件、端点开闭。
- [ ] 符号与下标前后一致；参数范围在每步都交代。

### 物理
- [ ] 量纲检查：每一项单位一致。
- [ ] 极限/特殊值：m→∞、v→0、θ→0/90°，结果是否符合物理直觉。
- [ ] 模型/约束类型：单侧（绳、内壁、轨道内侧，$N\ge0$ 或 $T\ge0$）还是双侧（杆、管、槽，可推可拉）——**这一项常常是唯一能判死错解的检查，量纲与极限可能同时通过**。
- [ ] 模型适用条件（光滑、轻绳、匀强场、准静态）是否写明。
- [ ] 单位与有效数字；矢量方向；符号约定（正方向）。
- [ ] 实验题：器材可得、步骤可操作、安全、误差来源。

### 化学
- [ ] 配平；原子/电荷/电子守恒。
- [ ] 反应条件（温度/催化剂/浓度）与现象一致。
- [ ] 过量/少量、先后顺序、竞争反应。
- [ ] 单位（mol/L、g、kJ）与有效数字。

### 生物 / 地理
- [ ] 图表信息与题干一致；坐标轴、单位、图例。
- [ ] 因果链完整，不跳步；概念不混用（如「种群」与「群落」）。
- [ ] 开放性作答给评分量规。

### 信息学
- [ ] 数据范围决定算法（n≤20 搜索？n≤2e5 线段树？）。
- [ ] 复杂度在限制内；常数与常数因子。
- [ ] 边界：n=0/1、空串、全相同、溢出、负数。
- [ ] 样例能过不代表边界能过；构造极端数据自测。
- [ ] 代码层已交付（编程题必查）：`code_drill_check` 0 error、`code_judge` 证据齐全（参考实现全过 / 骨架补全前失败 / 错解翻车），见 `code-training` 技能。

## 9. 质量门 rubric（0/1/2，总分 ≥23/28 才交付）

| # | 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|---|
| 1 | 答案核验与体检 | 没验题/没核答案直接拆 | 核了但漏边界或未做五类判定 | 盲解→对照→五类判定；条件/边界/多解全查 |
| 2 | 覆盖矩阵 | 子题与原题步骤对不上 | 大体对应 | 每行每列都有 ✓，无多余子题；k ≥ 断点数，n/b/k 理由已写 |
| 3 | 接口闭环 | 并排练习 | 有接口但有一处断 | 每题输出被下一题使用，无前向依赖 |
| 4 | 难度曲线 | 忽高忽低 | 总体上升但有一处跳崖 | 单调上升，回落有理由 |
| 5 | 无泄漏 | 学生版含答案或提示 | 无答案但有提示/元信息 | 学生版无答案、无提示、无元信息 |
| 6 | 全解自洽 | 答案与解析矛盾 | 个别步骤跳 | 每题答案/解析/评分点一致 |
| 7 | 学科校验 | 未做 | 做了一半 | 数值/量纲/守恒/边界/图形逐项过 |
| 8 | 学段合规 | 明显超纲 | 有一处超纲未标 | 全在学段内，拓展已标注 |
| 9 | 变式合规 | 类数不足或混标 | 有类别但构成不对（缺同质/异质） | 类数 ≥ 难度要求（或 2 类+裁剪说明），含同质+异质，类别/算子/轴/答案/Lean 齐全 |
| 10 | 时长匹配 | 明显超时 | 估算粗略 | 与用途匹配，误差 ±20% |
| 11 | 可诊断 | 错了不知道为什么 | 有常见错误但没回退路径 | 每题错误→误区→回退台阶 |
| 12 | 语言无歧义 | 符号未定义/有「显然」 | 个别含糊 | 符号/单位/图形齐全，无跳步词 |
| 13 | 坏题旗标 | 命中旗标却没写 | 写了但没处理 | 六类旗标逐一判过，命中项有处理动作 |
| 14 | 变式有效性 | 全是同题重做/换皮 | 部分有效 | 三判据全过；C 有反例、A 不冒充升维 |

**一票否决**：原题本身无解/矛盾却继续拆；编造真题出处；学生版泄漏答案或提示；变式答案错误；答案存在 P1–P5 伪证却未标注；模式 A 未做五类判定就把用户答案当依据；宣称 Lean「已验证」却拿不出 run 目录或文件仍有 `sorry`；**子题数 k < 断点数 b、覆盖矩阵有空行、有步骤/断点无台阶接住（漏台阶）**。

**答案核验硬门（模式 A/B）**：五类判定必须有证据（判 ✅ 需独立第二解法或 Lean `VERIFIED`；判 ⚠️ 需指出补哪一步；判 ❌ 需给反例）；判 ⚠️/❌ 时必须给错点定位与正确版本；解法族至少 2 条真正独立的解法（判据见 §2.5.4）。模式 C 必须先求助，不得硬编。

**三硬门（v1.4 口径，不计分，任一失败即不交付）**：
1. **Lean 硬门**：适用类题组（原题 + 每道子题 + 每道变式）全部 `VERIFIED`，附 run 目录、退出码、公理表；缺一条即不交付。不适用类逐题写理由。
2. **变式类数硬门**：类数 ≥ 难度要求（基础 2、中等以上 3）；**变式空间不足时任何题都可降到 2 类，但必须写「类别裁剪说明」**；每类 ≥1，且至少含 1 个同质类（A/B）+ 1 个异质类（C/D/E/F）；选 C 则必须附「默认做法失败」的 Lean 反例或严格反例。类别可扩展（G/H…），但必须写清判据。
3. **学生零提示硬门**：学生版出现任何提示、折叠提示、「卡住看提示」即返工。

**单文件/示例交付的变体**：只交付一份示例（不拆教师版/学生版）时，第 5 项按「可剥离性」评——题干与答案是否分区标注、H3 是否集中在教师区；不要因为「没做学生版」就直接判满分或零分。

**结构性泄漏**：定值/恒等式型证明题的组合台阶可能等价于原题答案（见 §5.7-6 ③），第 5 项最高 1 分并注明原因。

**交付形态门（不计分，失败返工）**：学生版精简 / 教师版单主线 / 支线隔离，见 §9.5.3；形态一票否决见 §9.5.3 末。

## 9.5 单主线与极简规范（交付形态门）

> 目标：教师版只讲**一条线**，学生版只留**最少的话**。形态不合格，内容再好也返工。

### 9.5.1 教师版：六环一条线

| 环 | 要回答的问题 | 产出 | 「过」的判定 |
|---|---|---|---|
| 1 目标 | 学生最后要能独立做什么 | 一句可测目标（含题号/时间） | 可观察、可打分 |
| 2 断点 | 学生会在哪一步断 | 1–4 个断点，按出现顺序；可加 0–2 道缓冲台阶 | 每个断点对应一个认知动作 |
| 3 台阶 | 每个断点用什么题接住 | 每断点一道台阶，只补一个断点 | 覆盖矩阵一行对一题 |
| 4 验收 | 怎么知道接住了 | 每级可观察通过标准 + 回退规则 | 不过不进下一环 |
| 5 回收 | 台阶结论怎么接回原题 | 接口表 + 原题分步对应 | 删任一台阶，原题做不了 |
| 6 迁移 | 变式往哪走 | 每道变式标注延伸的是哪一环 | 不另开主线 |

硬规则：
1. 教师版开头必须是「主线表」（上表 6 行），正文每节标题前标「接第 k 环」。缺主线表 = 返工。
2. **一条主线只允许一个主解法。** 其他解法、竞赛做法、更优技巧一律进文末「支线附录」，标「不占主线、不进学生版」。
3. 「入口分叉」只作教师应急备注（学生卡住时换哪条），不作并行教学路径；学生版不出现分叉。
4. 讲完一环再进下一环；不交叉引用未讲内容，不在第 2 环说「也可以用另一种方法」。
5. 支线附录 ≤1 节，不占课时，不计入「主线」质量评分。
6. **缓冲台阶（0–2 道）**：只做熟练度或防跳崖，不新增断点；必须写「防跳崖理由」，否则删掉或并入相邻台阶。

主线表模板（直接抄）：

```
| 环 | 一句话 |
|---|---|
| 1 目标 | 学生能独立完成【原题】，约 __ 分钟，允许 __ |
| 2 断点 | ① 断在 __（认知动作：表征）② 断在 __（转化） |
| 3 台阶 | 台阶 1 接断点①；台阶 2 接断点②；…… |
| 4 验收 | 台阶 1：能说出 __；台阶 2：能在 __ 分钟内写出 __；不过回退到 __ |
| 5 回收 | 第 k 题结论 → 原题第 __ 步；接口见下表 |
| 6 迁移 | v1 延伸第 3 环；v2 延伸第 5 环；v3 换情境不动主线 |
```

### 9.5.2 学生版：零提示，一页一件事

**逐题只保留三件东西**：题号 + 题干 + 作答区（选做加 ★）。**一个提示都不印**；所有提示归教师版与使用说明。

| 规则 | 上限 |
|---|---|
| 学生版总字数 | **≤ 1200 字**（绝对上限） |
| 题干外说明 | ≤ 1 行/题（说明行 = 非题干、非图表、非作答区的文字行） |
| 图表 | ≤ 1 图 + 1 表/题；图注 ≤8 字不计说明行 |
| 页数 | 作业版 ≤2 页双面；课堂版一页一题（≤7 页）；电子版不限 |
| 提示 | **0 条**：不印提示、不印折叠提示、不印「卡住看提示」 |
| 变式 | 只给题干 + ★（选做），不给类别与轴变化说明 |

**说明行与图表**：说明行只算「额外解释文字」；题干里的图表、单位、正方向约定不算说明行，但题干仍应 ≤2 行（含图表另起）。

**原题即台阶**：若台阶 k 就是原题，原题页即该台阶，不重复出题（不要出现「台阶 5」和「原题」两块）。

**禁止出现在学生版**：学习目标、知识点名称、台阶类型（T1/T2…）、「这题考什么」、D1–D5、P1–P7、评分点、诊断语、教师用词（「主线」「验收」「回退」「提示」）、任何答案、原题出处考据。

**写法示例**：

```
## 3
（题干，最多两行；图另起）
作答区：
```

不要写「提示 1（展开）：……」这类行，也不要写「第 3 题（表征台阶，目标是学会把文字翻译成方程）——」。

## 11. 常见失败模式（交付前对照）

1. **假台阶**：把原题数字改小当子题——学生做完仍不会原题。
2. **并排练习册**：子题之间没有接口，只是同一个知识点的多道练习。
3. **难度跳崖**：从套公式直接跳到需要构造辅助线，中间缺表征台阶。
4. **泄漏**：题干里写了「提示：用 XX 定理」，或学生版附了答案/提示。
5. **题眼重复计分**：同一个洞察在 R/C/A/T 里各加一次，D2 虚高。
6. **假变式**：只改数字/只换背景，却宣称「升维」。
7. **超纲**：用了目标学段没学的工具，未标注。
8. **数据不自洽**：几何图画不出、物理量纲不对、方程无解。
9. **堆题量**：10 道子题，学生做到第 4 题就跑了。
10. **提示=答案**：H1 就把关键观察说了；提示应分级且只由教师给。
11. **忽略诊断**：不知道学生缺什么，台阶全铺一遍。
12. **答案不唯一却按唯一答案判**：开放题没给量规。
13. **答案没核就拆**：把用户答案当权威，在错答案上搭了一整套台阶。
14. **伪证验收**：答案对但过程是跳步/循环论证/有限项代一般，没识别出来，还当标准解法教。
15. **假验证**：没编译、文件里还有 `sorry`，却写「Lean 已验证」；必须附 run 目录与退出码。
16. **学生版像讲义**：目标、知识点、台阶类型、解析全塞进去——学生先被文字劝退。
17. **两条主线打架**：教师版同时讲两种解法，学生不知道跟哪条，教师自己也讲乱。
18. **支线混入**：竞赛做法/拓展塞进学生版或主线课时，主线被稀释。
19. **学生版出现提示**：印了「提示 1/2」或 `<details>`，违背零提示硬门，直接返工。
20. **Lean 工件缺失**：适用类题组只验证了原题，子题/变式没 theorem；或只跑 `#check` 就写「已验证」。
21. **变式凑数**：类数不够硬凑、A 类只改字母却算升维、B 类没加条件、C 类没有反例、2 类不写裁剪说明。
22. **陈述漂移**：Lean 命题悄悄多了/少了假设（如漏 `x ≠ 0`），证的是另一道题。
23. **形式化拖到交付**：前面按自然语言拆完，最后才发现原题不可形式化，整组返工。

## 12. 参考：飘零式审题视角与理论依据

> 这一节是方法论来源，不是必须逐条执行；用它的「判断信号」来校准画像与质检。
> 完整证据版见 `references/飘零方法论.md`（449 行，含 BV 号与时间戳）与 `references/出题与脚手架理论.md`（347 行，含来源分级）。

### 12.1 drifter_飘零 的卷面分析视角（B 站数学 UP 主）

**一句话总纲**：难题的难度应来自「把条件翻译成结构」和「选对入口」，而不是「见没见过某个技巧」；卷子质量看**中段学生能不能拿到基本盘**，不看最高分；答案质量看**关键构造有没有来源**，不只对结论。

#### 真难度的 6 个来源（用来校准 D2/D3）

| # | 来源 | 在画像里落到哪 |
|---|---|---|
| 1 | 结构翻译：把条件译成正确数学对象 | D2-A 抽象、D5 隐含条件 |
| 2 | 入口选择：从不同入口进，复杂度天差地别 | D2-T 迁移、台阶的「入口分叉」 |
| 3 | 图形重建：从形成过程重造图，而非读现成图 | D2-A、D4 表征 |
| 4 | 完备性：分类讨论/端点不漏 | D2-C 论证 |
| 5 | 抽象符号阅读：把符号语言还原成朴素事实 | D2-A、D4 阅读量 |
| 6 | 计算负荷：真实存在，但属独立一维 | D4 计算 |

#### 假难度的 5 个来源与「纸老虎」

1. **包装/抽象化**：朴素事实写成抽象符号语言（「高情商叫多想少算」）。
2. **篇幅/表述绕**：题干长、从句多，读完先累。
3. **计算繁**：每步都会，但算到一半就错。
4. **位置错配**：中档位置塞顶级难度（选填/16、17 题位）。
5. **超纲技巧**：见过就会、没见过就死。

**纸老虎** = 吓人的条件 + 简单内核。判据：把条件翻译完后，如果只剩计算，就别当压轴。

#### 三条最硬的质检判据

1. **秒杀成本过低 + 没见过就必不会** → 难度 = 记忆抽签，不是思维难度（贯穿「高考补集」全片，出现 5 次以上）。
2. **全或无**：看出来就会、看不出来就零 → 中间层无信息，判「伪区分度」，须拆台阶或加中间问。
3. **变式空间枯竭**：某板块只有 1–2 个可变换维度（如概率统计压轴角度单一）→ 不做深度变式。

#### 均分崩 ≠ 题难（题单/卷子层面的体检）

衡水金卷均分 45、985 线 87、最高分 143：不是整体变难，而是 16/17 位置放「顶级难度 + 误导」→ **中段归零、尾部仍高分**，分布双峰化（「基本盘被吃掉」）。做整份题单/卷子时，画**难度-位置曲线**，标出「高位数送分 / 低位设卡」。

#### 模仿判定：禁用题面相似度

四步证据链：**核心考点 → 知识层级 → 解题第一步 → 所需洞察**。四步都相同才是真模仿；只是题干长得像、内核换了层级，是「换壳」。这条直接决定变式算不算「同题重做」。

#### 变式的 8 个维度（与本工作单 O 算子的对应）

| 飘零维度 | 含义 | 本工作单 |
|---|---|---|
| V1 换表征/换壳 | 同内核换情境/符号外衣 | O2 / O7 |
| V2 换入口 | 不改题，改「从哪进」 | 入口分叉 + 台阶重排 |
| V3 加耦合 | 多条件同时成立，或条件藏进前一问 | O6 / O4 |
| V4 调计算负荷 | 改到「可否被背下/可否被秒」 | O1（但单独标注） |
| V5 改设问层级 | 求值→恒成立→求范围→存在 | O3 |
| V6 加误导 | 图诱导 / 符号诱导 / 充分必要方向诱导 | O8 + 体检 |
| V7 调翻译难度 | 读题门槛 + 翻译确定性 | O7 / 题干改写 |
| V8 调退化解法通道 | 检查「取两项/代特值/猜结论」旁路 | 变式三判据 ③ |

#### 计算负荷 5 维与训练顺序

数值/数感 → 多项式规则 → 固定案例 → 技巧（且同时教通法如求导）→ 复杂环境下的结构敏感。**顺序不可跳**；背结果能提速但换板块会掉，且背错会「以为算对、检查不出来」。

#### 脚手架：按「入口分叉」而不是按「知识点顺序」

飘零的反常识主张：题型积累对考场发挥不总是正面的，先验模板会把新题强行归入旧类，反而堵死入口。所以教师手里要备**多条通路**（模板法 / 从结论反推 / 保底策略），但**课堂上只走一条主线**，分叉只在学生卡住时作为应急；学生版不出现分叉。他讲题时的台阶 = 先给目标，再给构造；先给判据，再给结论。

#### 使用边界（必须外显）

- 强应试导向，自限「120 分以下」适用；竞赛/强基/培优需重新校准。
- 他是事后评论者，不是命题者：没有双向细目表、没有预测试数据，只能当**质检检查表**，不能当命题规范。
- 「伪证」结论有单例风险（杭州一模只基于 1 道题、片尾 40% 是广告），引用时标「个案观察」。
- 判断「真难/假难」依赖他自己的水平，对目标学生不必然同构——**画像必须写「对谁难」**。

### 12.2 教学与命题理论（可执行版）

| 理论 | 一句话 | 落到本工作单 |
|---|---|---|
| 变式教学（顾泠沅） | 概念性变式（标准式/非标准式/反例）与过程性变式（铺垫/阶梯/拆步） | 概念性 → O2/O4；过程性 → 台阶链 |
| 变异理论（Marton） | 对比、分离（只变一个维度）、融合、概括 | 台阶「一次只加一个变量」= 分离；变式组 = 融合 |
| SOLO / DOK | 单点→多点→关联→抽象拓展；DOK 量复杂度 | 台阶至少跨两层；关联层必须出现「由上一问可得」 |
| 脚手架（Wood/Bruner/Rosenshine） | 小步呈现→示范→引导练习→检查理解→独立练习 | Gate 顺序；T1/T2 用 worked example |
| 认知负荷（Sweller） | 新手强指导降低外在负荷，熟练后撤除 | 新手给范例，熟练者直接给题；撤除顺序：提示→分解→范例，一次撤一级 |
| 提示过量（实证） | 给超过所需的支架，成绩反而下降 | H1→H2→H3 逐级，一次只加一级 |
| 问题提出（Brown & Walter） | What if not：列属性→逐个否定→生成→定级→筛选 | O5/O8 的生成器；变式「不可能无题」时用它 |
| 双向细目表 | 内容 × 认知层级矩阵 | 多题题单/卷子时给；单题不需要 |
| 难度系数 p | p = 平均分/满分；p<0.30 难，>0.75 易 | 只作经验预估，禁止伪装成统计估计 |

**争议提示（别把经验说成定论）**：DOK 量的是复杂度，不等于难度；「变式教学」不等于 variation theory；worked example 对熟手是否一定反效果仍有争议（expertise reversal 有边界）。输出里凡属经验判断，标「经验预估」。

### 12.3 Lean 4 形式化验证（强制，适用类）

完整手册见 `references/Lean形式化验证.md` 与插件技能 `lean-formalization`。一句话协议：**适用类（数学/几何/算法/计算）原题、每道子题、每道变式都要有 theorem 且 `lean_verify` 判定 `VERIFIED`；没有 run 目录、退出码、公理表就不许交付**。形式化证的是 theorem，不证明 theorem 忠实于原题——假设与结论必须逐条对账。不适用类逐题写理由，不许用「Lean 不适合」一句话带过整份题组。

```
答案：A 有答案 = 盲解→对照→五类判定→反推解法族；B 无答案 = 双路线自解；C 解不出 = 说卡点+请用户给正解，不硬编

解法族：目标反推 / 中间量反推 / 特殊值反推 / ≥2 条独立解法 / 出题意图 / 可迁移模板
验证强度：L0 第二解法 · L1 Python/SymPy · L2 Lean（适用类强制：退出码 0 + 无 sorry + 公理干净 + run 目录）
体检：条件用全 / 无矛盾 / 自解 / 验算 / 边界 / 多解 / 出处
旗标：纸老虎 / 全或无 / 秒杀通道 / 换壳 / 位置错配 / 伪证
画像：D1 重复 · D2 R/C/A/T · D3 叠加 · D4 计算表征 · D5 陷阱决策 → 真难/假难/综合/没难度
台阶：先数 n/b，按难度定 k（基础 2–3 / 中等 4–5 / 难 5–7 / 竞赛 6–8）；每步每断点都有台阶，不许漏
变式：类数按难度/空间定（基础 2、中等以上 3，可 4–6）；含同质+异质各 ≥1；C 必附反例；2 类写裁剪说明
主线：目标→断点→台阶→验收→回收→迁移；教师版只走一条线，其他解法进支线附录
学生版：题号+题干+作答区（零提示）；无元信息；说明≤1 行/题；≤1200 字；作业≤2 页/课堂一页一题

```
