# 题目拆解与变式设计师（DSH Agent 预设 · problem-forge）

> 一句话定位：给一道题（任何一个有明确求解目标的学科题），产出一条「从不会到会」的路——
> **答案核验 → Lean 形式化验证 → 反推解法族 → 五轴难度画像 → 按难度定子题数 → 按空间定变式类目**，
> 交付教师版（单主线）、学生版（零提示）、使用说明与 `formal/` Lean 工件。

> English abstract: A DeepSeek Harness agent preset that turns a single problem into a
> teachable ladder. It first verifies or independently solves the answer, formalizes the
> applicable ones (math / geometry / algorithm / computation) in Lean 4 + Mathlib and only
> accepts kernel-verified results, reverse-engineers the solution family, scores the problem
> on five difficulty axes (repetition, reasoning depth, knowledge stacking,
> computation/representation, traps), then designs a difficulty-scaled number of scaffolded
> sub-problems plus 2–5 classes of variants and delivers a teacher edition, a hint-free
> student worksheet, and a usage script. Install it as a DSH bundle and select the preset in
> a new session.

教师版**只走一条主线**（目标 → 断点 → 台阶 → 验收 → 回收 → 迁移），其他解法与拓展全部进支线附录；
学生版**零提示**，每题只留题号、题干与作答区，所有 H1–H3 提示归教师。

不限于编程题：数学、物理、化学、生物、信息学都能用；数学/几何/算法/计算类强制过 Lean 形式化验证；
人文社科走「材料—论证」版本（数据校验换成论证校验）。

## 它解决什么问题

| 你的痛点 | 它给什么 |
|---|---|
| 「这题太难，学生接不住」 | 把题眼与认知步骤拆开，补前置知识、铺台阶，每级只加一个变量 |
| 「讲完了学生还是不会做原题」 | 子题与原题用「接口」串起来：上一题的结论就是下一题的输入，覆盖矩阵保证不脱节 |
| 「想分层作业，不知道从哪切」 | 子题数按难度定（基础 2–3 / 中等 4–5 / 难 5–7 / 竞赛 6–8），每级用时/提示/诊断点，直接排 40 分钟课堂或分层作业 |
| 「想一题多变，但只会改数字」 | 变式类目动态选 2–5 类：简单题 2 类（同质+异质）即可，中等以上 3 类起；A 同质异述、B 同质增条件、C 形似神异、D 逆向、E 错解辨析、F 推广/特殊化，也可自定义 |
| 「不知道这题到底难在哪」 | 五轴画像：思维深度（R/C/A/T）、知识叠加、计算与表征、陷阱与决策、重复度；判真难/假难 |
| 「答案/解析不放心」 | 有答案先盲解再核验，五类判定，伪证七类逐条查，错点定位到原句 |
| 「学生版太厚，学生不看」 | 学生版零提示：每题只有题号/题干/作答区（选做加 ★），无目标、知识点、台阶类型、难度等元信息，也不印任何提示；≤1200 字，作业版 ≤2 页双面 |
| 「讲着讲着就乱了」 | 教师版强制六环单主线表，每节标「接第 k 环」；其他解法与拓展全部进支线附录，不并行讲 |
| 「想要多种解法，但只会一种」 | 从正确答案反推解法族：目标/中间量/特殊值反推，至少 2 条独立解法，标最简与最通用，还原出题意图 |
| 「自己也不确定解得对不对」 | 三级验证：L0 第二解法 → L1 Python 精确验算 → L2 Lean 4 形式化（`✅ 内核已验证`、附 run 目录与公理表才算）；适用类没做不交付 |
| 「出的题经不起推敲」 | 数学/几何/算法/计算类每题（含子题、变式）强制形式化：缺一条 theorem、有 `sorry`、拿不出 run 目录 → 不交付 |

## 五轴难度画像

| 轴 | 含义 | 借鉴 |
|---|---|---|
| D1 重复度 | 与教材例题/真题/经典题的骨架相似度 | 命题质量审核员 D1 |
| D2 思维深度 | R 推理链 / C 因果论证 / A 抽象建模 / T 迁移跨方法 | 命题质量审核员 D2 |
| D3 知识叠加 | 知识点清单 + 单点/串联/并联/嵌套 + 耦合强度 | 命题质量审核员 D3 |
| D4 计算与表征 | 计算五维（数值/规则/案例/技巧/结构敏感）+ 表征转换次数 + 阅读量 | drifter_飘零「计算核心能力」 |
| D5 陷阱与决策 | 默认解法是否必错、坑的隐蔽度、是否需要检验/反例 | drifter_飘零「坑/伪证/真难假难」 |

一句话结论落在：**真难 / 假难 / 综合难 / 没难度**。D4 高而 D2 低 = 假难；D3 高而 D2 低 = 大杂烩。

## 工作流

```text
G0 需求确认（≤3 问，含「有没有答案」）
G1 答案核验 / 独立自解 + 题目体检：五类判定、条件用全、边界、多解、出处
G1.5 Lean 形式化（适用类硬门）：原题 + 子题 + 变式逐条 theorem，整组一次编译
G2 反推解法族：目标 / 中间量 / 特殊值反推 + ≥2 条独立解法 + 出题意图 + 可迁移模板
G3 解剖与画像：题眼 → 解法路线 → 认知步骤 → 五轴
G4 台阶设计：数认知步骤 n 与断点 b → 按难度定 k → 覆盖矩阵（不许漏）+ 接口表 + 难度曲线
G5 子题撰写：k 道（基础 2–3 / 中等 4–5 / 难 5–7 / 竞赛 6–8），逐题自解 + 子题 theorem
G6 变式生成：按空间选 2–5 类，每类 ≥1，含同质类 + 异质类；逐题自解 + 变式 theorem
G7 按主线组装 + 14 项质量门（≥23/28）+ 形态门 + 三硬门 + 交付
```

## 三级验证（L0 / L1 / L2）

按「L0 自然语言 + 第二解法 → L1 Python/SymPy 精确验算 → L2 Lean 4 形式化」逐级上，**不许跳级宣称**：

- **L0**：写出至少两条独立解法（三项中两项不同才算独立），互相交叉验证。
- **L1**：用 Python（`fractions` 精确算术 / 数值扫描 / 符号恒等式）逐项验算，脚本随仓库放在
  `examples/verify/`，见「示例产出」。
- **L2**：适用类（数学/几何/算法/计算）**强制**：写 `formal/Problem.lean` → `lean_verify` 内核判定，
  退出码 0、无 `sorry`、公理干净、拿得出 run 目录才叫 `VERIFIED`；不适用类逐题写「非形式化类 + 理由」，
  **不许用未编译骨架冒充已验证**（细节见 `skills/problem-forge/references/Lean形式化验证.md`）。

## 台阶数量：按难度定，不许漏

先数原题**认知步骤** $n$（3–7）与**断点** $b$（1–4），再取子题数 $k$：

| 档 | 判据（满足任一） | 子题数 $k$ |
|---|---|---|
| 基础/单点 | $n\le3$ 且 D2≤2.5 且 D3≤2 | **2–3** |
| 中等 | $n=4–5$，或 D2 3–4，或 D3 3–4 | **4–5** |
| 难/综合 | $n\ge6$，或 D2≥4.5，或 D3≥5 | **5–7** |
| 竞赛/压轴 | $n\ge6$ 且 D2/D3 高 | **6–8** |

硬约束：$k \ge b$；每个认知步骤至少被 1 道子题覆盖；每个断点至少被 1 道台阶接住；**覆盖矩阵不许有空行**。
宁可多一道，不许漏一个断点/步骤。缓冲台阶 0–2 道（只做熟练度/防跳崖，不新增断点）。

默认骨架：`诊断?(可选) → 复现 → 表征 → 题眼 → 组合 → 原题`；实际数量按上表，不硬凑 4 道、也不为省事少拆。

**判断台阶好坏的标准**：删掉第 k 题，第 k+1 题会怎样？分三档——做不了（强，合格）；能做但要多绕一步/多踩一个坑（中，算串联）；可原样完成（弱，就是并排练习册，删题或合并）。

## 变式：类目动态，至少两类

先判变式空间，再定类数；**不是固定三类**：

| 类 | 定义 | 例子 | Lean |
|---|---|---|---|
| **A 同质异述** | 本质相同，描述/表征/情境不同；D2 不变 | 换字母、换情境、换图 | 同一命题等价实例 |
| **B 同质增条件** | 本质相同，加条件/参数/耦合；D2 或 D3 升 ≥1 | 加「x>0」、由二次到三次、串联两个模型 | 带新增假设的强命题 |
| **C 形似神异** | 表面相似，默认解法失效，需换解法/更难知识 | 同样给和与积，但判别式 <0，套公式必错 | 先证默认命题为假，再证正确命题 |
| **D 逆向/换设问** | 结论↔条件、求值↔范围↔存在↔恒成立 | 已知答案反求参数范围 | 逆命题/范围/存在性 |
| **E 错解辨析** | 给错误解法找错、判断伪证 | 两种解法一个漏定义域 | 反例或漏洞 |
| **F 推广/特殊化** | 一般化、参数化、2D→3D 或取特殊情形 | 三角形→四面体 | 更强/更广命题 |

**类数与道数**：基础/单点题最少 **2 类**（1 同质 + 1 异质），3–4 道；中等以上最少 **3 类**，4–5 道；
难/综合可 3–5 类、5–6 道；开放/多维度可 4–6 类。**2 类必须写「类别裁剪说明」**（为什么第 3 类没有空间）；
类目不够可自定义 G/H，写清定义与判据。

九类算子（O1–O9）仍可用，但交付时统一归到所选类目；O1 只算熟练度，O9 属台阶。
选 C 就必须附反例（Lean `¬` 或严格数值反例）；不选 C 不强制。

## Lean 形式化验证（数学/几何/算法/计算类强制）

已整合 `lean-verify` 插件（`lean_env` / `lean_verify` / `lean_probe`）；工具链与 Mathlib 工程需自行准备
（见「依赖与兼容性」）：

- Lean **4.35.0**（managed）；Mathlib 工程放在插件数据目录下（本机为 `~/.dsh/lean-verify/mathlib-src`，
  已构建，`import Mathlib` 可用）。
- 每个题组写一份 `formal/Problem.lean`：原题 `base_*` + 每道子题 `stepN_*` + 每道变式
  `varA_*` / `varB_*` / `varC_*` / `varD_*`…，**整组一次编译**。
- 判定只认 `✅ 内核已验证`：退出码 0、无 `sorry`/`admit`、公理 ⊆ `{propext, Classical.choice, Quot.sound}`；
  附 run 目录（`~/.dsh/lean-verify/runs/...`）、退出码、公理表。
- 缺一条定理、`sorry`、自定义公理、只跑 `#check`/`#eval`、拿不出 run 目录 → **不交付**。
- 纯尺规作图、实验设计、开放论述、无唯一答案的建模 → 标「非形式化类」并逐题写理由。
- 形式化证的是 theorem，不自动证明它忠实于原题；每条 theorem 都要写「假设 ↔ 题面，结论 ↔ 所求」的对账。
- 详细协议见技能 §2.6 与 `skills/problem-forge/references/Lean形式化验证.md`；真实跑通的模板见
  `examples/示例_Lean强制验证_三类变式.md` 与 `examples/formal/`。

## 交付形态：教师版单主线，学生版极简

**教师版六环一条线**（固定顺序，不许跳环、不许并行）：

| 环 | 回答什么 |
|---|---|
| 1 目标 | 学生最后要能独立做什么（一句可测） |
| 2 断点 | 学生会在哪一步断（1–4 个，按出现顺序；可加 0–2 道缓冲台阶） |
| 3 台阶 | 每个断点用哪道题接（一题只补一个断点） |
| 4 验收 | 怎么知道接住了（可观察标准 + 回退） |
| 5 回收 | 台阶结论怎样接回原题（接口对应） |
| 6 迁移 | 变式延伸的是哪一环（不另开主线） |

教师版开头必须有 6 行「主线表」，每节标「接第 k 环」；**一条主线只允许一个主解法**，
其他解法/竞赛做法/更优技巧进文末「支线附录」，标注「不占主线、不进学生版」。

**学生版零提示**：每题只保留 **题号 + 题干 + 作答区**（选做加 ★）。禁止出现学习目标、
知识点名称、台阶类型、「这题考什么」、D2/D3、P1–P7、评分点、教师用词、任何答案，以及**任何提示**
（含「卡住看提示」）——H1–H3 只进教师版提示卡，由教师按卡住信号口头给。
题干外说明 ≤1 行/题，总字数 ≤1200 字（绝对上限），作业版 ≤2 页双面 / 课堂版一页一题。

## 安装

**前置条件**：DeepSeek Harness 桌面版（`desktop` profile）、Node ≥ 22。
**L2 Lean 形式化验证需要额外安装 `lean-verify` 插件并准备 Mathlib 工程**（GB 级，见「依赖与兼容性」）；
未装时预设仍可拆题，但适用类会停在「待形式化」，不会假称已验证。

```text
# 1) 克隆仓库（仓库地址以你 fork/克隆的为准）
git clone <你的仓库地址> dsh-problem-forge-preset
cd dsh-problem-forge-preset

# 2) 把技能目录的绝对路径写进 cordis.patch.yml
#    DSH 的 skill-filesystem 用 path.resolve() 解析 bundledSkillDir，相对路径不可靠，
#    所以仓库里这一行默认是注释掉的，必须跑一次脚本写入本机绝对路径。
node scripts/set-skill-dir.mjs

# 3) 安装 bundle
plugin_manager action=install_bundle target="<克隆后的仓库绝对路径>"
```

安装后**新建会话**，在 Agent 预设列表选择「题目拆解与变式设计师」。已开着的会话不会切换。

> 跳过第 2 步也能用：persona 里已写「技能加载失败就按提示词框架继续」的兜底，
> 只是拿不到 SKILL.md 与 `references/` 里的方法论细节。

卸载：`plugin_manager action=remove_bundle target="dsh-problem-forge-preset"`，或从 profile 的
`package.json` 的 `dsh.profile.bundles` 里移除后执行 `pnpm install`。

## 使用

最小可用示例（直接在会话里说）：

```text
这题：<贴题目>。高二普通班，40 分钟，只要教师版 + 台阶地图，学生版 ≤2 页。
```

七种常见用法：

1. **课堂例题**：贴题目 + 说「高二，普通班，40 分钟，只要教师版和台阶地图」。
2. **验答案**：贴题目 + 你的答案/解析，说「先核验，再告诉我错在哪；如果对，反推 2–3 种解法」。
3. **只给题**：说「没答案，你先解；解不出就告诉我卡在哪，别硬编」。
4. **分层作业**：说「按基础/中等/拔高三层出题单，学生版不带答案」。
5. **一题多变**：说「按这道题的变式空间选类目，简单就 2 类，别硬凑三类；要一道 C 类（形似神异）」。
6. **形式化**：说「这题用 Lean 形式化验证，子题和变式也要；拿不出 run 目录就不要说已验证」。
7. **审题**：只想判断「这题难在哪、值不值得用」时，说「只出体检 + 画像，不拆题」。

## 依赖与兼容性

- **DSH**：桌面版（`desktop` profile），随包工具 `plugin_manager` / `skill`。
- **Node**：≥ 22（已在 Node 22.19 上验证；`scripts/set-skill-dir.mjs` 无第三方依赖）。
- **平台**：已在 Windows 11 上验证；验算脚本只用 Python 标准库，跨平台可用。
- **外部依赖**：`lean-verify` 插件（提供 `lean_env` / `lean_verify` / `lean_probe`）与 Lean 4 + Mathlib
  工程（GB 级安装，不随仓库提供）。未装时适用类停在「待形式化」，不会假装已验证。

## 已知限制

1. **依赖模型自身的解题能力**：极难竞赛题（如 IMO/CMO 压轴）自解可能不稳，产出需人工复核；
   解不出时会走「模式 C」求助，而不是硬编。
2. **答案核验同样受自解上限约束**：判「❓ 无法判定」是合法结论，不代表答案错。
3. **Lean 形式化依赖外部环境**：需要 `lean-verify` 插件与已构建的 Mathlib 工程（GB 级，首次
   `import Mathlib` 约 1–3 分钟）；未装时适用类只停在「待形式化」，不交付。形式化证的是你写的
   theorem，不自动证明它忠实于原题，假设与结论必须逐条对账。
4. **不替代教材与考纲**：学段边界按常见教材口径估计，精确对齐请提供教材版本。
5. **难度档位是相对估计**，不是等距量表；同一道题不同学生感受不同，需按学情微调。
6. **人文社科**只做「材料—论证」脚手架，不适合需要大量背景知识的开放性论述题。
7. **`bundledSkillDir` 必须跑 `node scripts/set-skill-dir.mjs`**，否则技能不出现（预设本身仍可用）。
